# تواصل العطا — v1.0.56 / build 156

## تعديل مؤكد في كود المصدر
- مربع البحث في عنوان «يوتيوب»، القرآن، الأحاديث، الأذكار والأصدقاء: شريط واحد ارتفاعه 39dp وعرضه 184dp، بلا مربع ثانٍ داخل قائمة الأصدقاء.
- قائمة الأصدقاء: اقتراحات الأشخاص وزر «إضافة صديق» في نفس صف المستخدم. صفوف الأصدقاء أكثر إحكامًا، وبها رموز للمحادثة والمكالمة الصوتية والفيديو. تبقى طلبات الصداقة وقواعد الخصوصية كما هي.
- YouTube: بدلاً من مستند HTML مُنشأ عبر `loadDataWithBaseURL` وحقن IFrame API (الذي لم يكن مماثلاً تماماً للموقع)، تفتح WebView موقع تواصل العطا الحقيقي بنفس أصل HTTPS الذي يعمل في Chrome، ثم تضيف **iframe واحدًا** من نفس `youtube-player-shared.js` الذي يستخدمه الموقع. جرى حذف إعادة بناء iframe عبر `YT.Player` لتجنب استبداله أو إفساد عرضه.
- يسمح إعداد WebView بملفات تعريف الارتباط الخارجية ويحافظ على نسبة 16:9 وعرض الشاشة.
- زر «فتح في YouTube» يبقى خياراً إذا منع YouTube تشغيل الفيديو داخل WebView.
- الإصدار والتوقيع الرسميين: نفس package/signing، رقم الإصدار صار `1.0.56` والبناء `156`.

## حدود التحقق
- نجحت فحوص المصدر وJavaScript والاختبارات المحلية.
- تعذّر إجراء بناء Android وتشغيل WebView على هاتف HONOR في هذه البيئة؛ **تشغيل الفيديو لم يُثبت بعد**. يلزم تجربة APK الجديد على الهاتف؛ إن ظهرت شاشة سوداء، يلزم سجل Logcat للـWebView/Chromium أو رسالة الخطأ قبل تغيير المشغّل من جديد.
- مشغّل الفيديو يحتاج اتصالاً بالموقع العامل أثناء التشغيل؛ لا يحتاج صفحة نشر إضافية على Cloudflare.
