# عطا ستريم — تطبيق قنوات أندرويد مستقل

**الإصدار:** 1.0.1 (versionCode 2)  
**الحزمة:** `com.alatta.stream`  
**الهدف:** تطبيق عربي مستقل مستوحى من نمط أدلة القنوات، لكن بواجهة وكود وشعار أصليين. لا يحتوي على كود أو شعارات أو مفاتيح أو مصادر بث من Yacine TV.

## الموجود في النسخة الأولى

- واجهة داكنة وعناوين ذهبية؛ عربية RTL؛ قناة ببطاقة ومشغل داخل الشاشة.
- الأقسام، البحث، المفضلة، آخر مشاهدة، إضافة وحذف القنوات.
- مصدر JSON مركزي عبر HTTPS؛ تحديث من زر «تحديث»، ومزامنة تلقائية عند افتتاح التطبيق.
- مشغل واحد فقط عبر AndroidX Media3/ExoPlayer يدعم HLS وDASH وMP4 عند توفر المصدر ودعمه.
- MediaSessionService لاستمرار **الصوت** في الخلفية وفق سياسات أندرويد ومحددات الجهاز، مع التحكم من الإشعار.
- صورة داخل صورة للفيديو (PiP) على الأجهزة الداعمة، عند تشغيل الفيديو ثم الرجوع للشاشة الرئيسية.
- تم تضمين فيديو اختباري واحد بعنوان «فيديو تجريبي HLS» للتحقق من المشغل فقط، وليس قناة تلفزيونية أو مصدر بث قابلًا للتوزيع تجاريًا.

## فتح المشروع وبناء APK

1. فك الضغط وافتح **مجلد AttaStreamAndroid** في Android Studio.
2. استخدم Android SDK API 36 وJDK 17، واسمح بمزامنة Gradle من الإنترنت.
3. لتجربة التشغيل اضغط Run على هاتف Android 8.0+.
4. لإنشاء APK: **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. أو ارفع المشروع إلى مستودع GitHub جديد ثم شغل **Actions > Build Atta Stream APK > Run workflow**. ستجد Debug APK في Artifacts بعد بناء ناجح. يعمل debug APK للتجربة، وليس للنشر بالمتاجر.

**ملاحظة:** تم تضمين gradlew / gradlew.bat مع تهيئة تحميل ملف gradle-wrapper.jar الرسمي في أول تشغيل؛ الملف الثنائي غير مضمن داخل ZIP. GitHub Actions يستخدم Gradle 8.13 الذي يثبته بنفسه.

## إضافة قناة من داخل التطبيق

- اضغط **＋ قناة**، واكتب اسم القناة، تصنيفها، ورابط البث HTTPS المرخّص.
- اضغط البطاقة للتشغيل، والنجمة للمفضلة، واضغط مطولًا للحذف.
- للمشاهدة في الخلفية أبقِ القناة تعمل. زر النافذة العائمة يظهر الفيديو إن سمح الهاتف.
- روابط البث غير المشفرة HTTP مرفوضة افتراضيًا لأمان الاتصال. لا يتم تجاوز DRM أو طلب بيانات الوصول إلى خدمات أخرى.

## ربط قائمة قنوات متجددة

ارفع ملف JSON إلى نطاق HTTPS تديره ولديك صلاحية استخدامه، واتبع نموذج `sample-catalog.json`.

```json
{
  "version": 1,
  "channels": [
    {
      "id": "sports-01",
      "name": "اسم قناة مرخصة",
      "category": "رياضة",
      "streamUrl": "https://licensee.example/channel.m3u8",
      "description": "بيانات القناة",
      "enabled": true
    }
  ]
}
```

افتح «⚙ المصدر» وأضف رابط ملف JSON. كل تعديل لاحق على نفس الملف يظهر بعد فتح التطبيق أو الضغط على «⟳ تحديث» من دون تغيير APK. يستخدم التطبيق المعرّف `id` لمنع تكرار القناة؛ يحذف من الذاكرة القنوات التي أُزيلت من المصدر في التحديث التالي، مع الاحتفاظ بالقنوات اليدوية.

## الاعتبارات والحدود

- **ليست هذه نسخة من Yacine TV:** لا يوفر تشغيل قنواته تلقائيًا، ولا ينسخ هويته أو واجهات API الخاصة به.
- روابط البث المرخّصة مطلوبة. بعض الروابط قد تتوقف بسبب انتهاء الصلاحية أو القيود الجغرافية أو DRM أو متطلبات مشغل خاصة.
- الاتصال والتخزين المحلي بسيطان. النسخة الأولى لا تتضمن تسجيل دخول أو إدارة خادم أو توصيات ذكية أو دليل برامج EPG.
- مشغل الخلفية قد يتأثر بقيود البطارية وبيانات الهاتف. PiP لا يعني فيديو خفيًا داخل كل التطبيقات.
- هذه **شيفرة مصدرية** وليست APK مبنيًا. لم يتم تشغيل Android Gradle Build هنا لغياب Android SDK واتصال تنزيل dependencies. اختبر البناء والتشغيل على جهاز حقيقي قبل النشر.

- نموذج اختبار HLS: https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8 — محتوى اختباري (Big Buck Bunny). لا تستخدمه كبث إنتاجي.

## تنظيم الملفات

- `app/src/main/java/com/alatta/stream/MainActivity.kt`: التصميم، القنوات، المشغل الصغير، التفاعل.
- `ChannelStore.kt`: قاعدة القنوات المحلية ومصدر JSON والتحقق.
- `PlaybackService.kt`: MediaSessionService وExoPlayer واحد.
- `Channel.kt`: نموذج القناة.
- `.github/workflows/android-debug.yml`: بناء تلقائي تجريبي على GitHub.
