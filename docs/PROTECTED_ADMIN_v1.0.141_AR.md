# تواصل العطا 1.0.141 / 241

يحمي هذا الإصدار حساب المدير الرئيسي في الخادم والواجهتين. أُلغي مسار حذف المدير و`deleteAll`؛ كما تُرفض خطط التصفير القديمة بعد النشر. الحذف الجماعي له نطاقان واضحان: الحسابات عدا المدير، أو المنشورات فقط. حذف الحسابات يعيد استخدام تنفيذ الحذف الفردي الموجود، بدفعات قابلة للاستكمال بعد انقطاع الشبكة أو إعادة تشغيل الخادم. تبقى جلسة المدير وكلمة الحماية ووسائطه عند حذف بقية الحسابات. حذف المنشورات وحدها لا يمس الحسابات أو وسائط الملفات المشتركة.

إعداد كلمة حماية الإدارة أو تغييرها يحتاج كودًا يُرسل إلى البريد المعتمد في SUPER_ADMIN_EMAIL ومن جلسة المدير نفسها. لا يكفي امتلاك جلسة دخول مسروقة لإعدادها. الكود صالح عشر دقائق وخمس محاولات، مع دقيقة بين طلبات الإرسال. تُخزن كلمة الحماية بتجزئة PBKDF2 مملحة، ويُمنع استخدام كلمة دخول الحساب نفسها. الحذف، تعديل أسماء الحسابات أو نصوص المنشورات، إدارة المشرفين وتصدير النسخ التي تتضمن أسرار الجلسات تحتاج كلمة الحماية في كل طلب. خمس كلمات خاطئة تقفل التحقق خمس عشرة دقيقة عبر جميع الجلسات. الواجهات لا تحفظ الكلمة في تفضيلات أو تخزين المتصفح.

يمكن إضافة مشرف أو إزالته من نتيجة البحث عن حساب. صلاحيات المشرف تقتصر على قراءة لوحة المتابعة ومراجعة البلاغات وإيقاف الحسابات العادية وإعادة تفعيلها؛ لا يحذف حسابات أو منشورات الآخرين، ولا يغير البيانات أو يضيف مشرفين، ولا يوقف المدير أو مشرفًا آخر. لا تُعاد تفعيل منح الإشراف القديمة المهجورة تلقائيًا. يحتفظ كل مستخدم بحق حذف منشوراته المعتاد.

تستخدم الملفات الشخصية الذاتية والعامة رأسًا مشتركًا في أندرويد: غلاف، صورة شخصية متداخلة، اسم واضح، عدد الأصدقاء وأقسام الملف. الموقع يستعمل الهيكل نفسه للمالك والصديق، مع أزرار التعديل للمالك فقط وقيود الصداقة والمراسلة القائمة. أضيفت مساحات أسفل شريط التنقل ورفع قيود ارتفاع/تمرير الغلاف في نسخة الهاتف والموقع المثبت، وتغير إصدار كاش الموقع إلى 14.1.

التحقق: اختبارات الخادم ببيانات معزولة تغطي سرقة الجلسة دون كلمة الحماية، البريد والكود والمحاولات، منع حذف المدير، صلاحيات المشرف، منع تجاوز المسار القديم لحذف المنشورات، الاستكمال بعد فشل الوسائط وإعادة التشغيل، وحذف أكثر من 200 منشور. اختبارات DOM تغطي كلمة المرور المقنّعة والخصوصية وأزرار الملف والأدوار. لا يتم حذف بيانات حقيقية أو إنشاء مشرفين حقيقيين أثناء الاختبار. يلزم نجاح بناء أندرويد والتوقيع قبل إصدار APK. تعذر الفحص البصري في متصفح المعاينة المحلي بسبب عدم اتصال المتصفح بالخادم المحلي؛ لا يُدّعى التطابق البصري لكل بكسل أو اختبار لمس فعلي على هاتف.
