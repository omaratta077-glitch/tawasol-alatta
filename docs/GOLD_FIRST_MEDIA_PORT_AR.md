# Gold-first — نقل Media إلى حزمة الذهبية الناجحة (مسودة تجريبية)

**تحذير: لا يوجد إثبات تشغيل صوت وصورة، ولا نسخة صالحة للنشر حتى الآن.**

## الاتجاه الجديد
- تحتفظ حزمة `com.ytv.pronew` بمحرّك `dev.google.ytvplayer.YtvApp` الأصلي وبموارد Gold في `0x7f`.
- تدخل الشاشتان من نقطة Gold-first اسمها `GoldFirstHubActivity`: زر القنوات يفتح Gold Player الأصلي، وزر Media يفتح `com.alatta.nativeapp.MainActivity` **داخل نفس التطبيق**.
- يجري تشغيل أنشطة وخدمات Media في عملية منفصلة `:media` بمصنع `GoldFirstAppComponentFactory` لإنشاء `AttaApplication` دون استبدال Gold Application في العملية الرئيسية.
- مصدر Media المنقول يتضمن كل شاشاته وخدماته وحزم أصوله الأصلية؛ لكن وجودها داخل APK لا يضمن عملها وقت التشغيل.
- لا توضع ملفات Gold الثنائية أو الموارد المحمية في GitHub العام.

## نتائج فحوص النسخة الثنائية الخاصة (6 نوفمبر 2026)
- **Gold**: 13,092 فئة في `classes.dex` الأصلي (SHA-256 `7208074b98b1b504dd83f7cf281bb2a9cefa0e741405f30ce0186aee1d623d22`) وجميع موارد Gold `0x7f` الأصلية (6,565 معرّفًا) ومكتبات ARM64 الأصلية محفوظة بالبايتات.
- **Media**: 28,484 فئة في بناء GitHub، أُزيلت 127 فئة تصادم مع Gold، فبقيت 28,357 فئة، ورُحّلت 3,381 قيمة مورد من نطاق `0x7f` إلى `0x80`. جرى تحليل 171,677 دالة DEX دون تعذّر تحليل.
- **الموارد**: 860 معرّف Media في `0x80`، و441 ملفًا `res/at_media`، مع إعادة ربط مسارات وقيم XML والسلاسل في جدول موارد ثنائي.
- **Manifest**: احتفظ Gold بـ`YtvApp` وPlayerActivity الأصليين؛ أضيفت 21 صلاحية/ميزة و54 مكوّنًا وإعدادًا من Media؛ بقيت 5 تعريفات اعتماد مشتركة بحاجة لفحص واجهات الخدمات لا مجرد إضافة نسخ مكررة. جعل `allowBackup=false` لخصوصية الحسابات.
- **فحوص Android الرسمية**: AAPT2 قرأ موارد/Manifest الحزمة، و181 XML مترجمًا لـMedia، وفحص `dexdump` ملفات DEX، و`zipalign -P 16 4`، و`apksigner` يتحقق من التوقيع الاختباري v3. لا توجد تعريفات فئات متكررة ولا مراجع Media لموارد غير معرّفة.
- **التوقيع**: مفتاح مختبر مختلف عن Gold الحقيقي؛ ملف بنفس `com.ytv.pronew` لا يثبت فوق Gold المثبت. وُجدت نسخة Clone جانبية باسم `com.ytv.pronew.goldfirstlab` للاختبار فقط، **لكن هوية الحزمة المختلفة قد تؤثر في خدمة Gold/الترخيص**.
- بناء مصدر Media واختبار `GoldFirstTargetsTest` نجح عبر GitHub Actions `42232436923`؛ دون رفع Gold الثنائية.

## ما زال غير مؤكد
1. Android PackageManager، تحميل AssetManager للحزمة الثانوية `0x80` داخل APK واحد.
2. إقلاع Gold YtvApp ثم Media AttaApplication في العملية المستقلة، وتشغيل كل شاشاتهما.
3. تشغيل قناة مصرح بها بالصوت والصورة مع مكتبات Gold JNI.
4. توصيل كل مكوّنات Media (قرآن، الأذكار، الأحاديث، منشورات، رسائل، مكالمات، إشعارات، أذان، فيديوهات، Google Sign-In).
5. تصادم مكتبات Google/AndroidX المشتركة حتى بعد إزالة تعريفات DEX المتكررة؛ وفحص أحداث تسجيل الدخول وFCM لحزمة Gold الجديدة.
6. التوقيع الرسمي، آلية التحديث، الترحيل الآمن لبيانات المستخدم، وترخيص ملفات Gold والخدمات قبل التوزيع.

**ممنوع دمج هذه المسودة في main أو رفع APK كمحدّث رسمي حتى يتم اختبار هاتف ARM64 ناجح.**
