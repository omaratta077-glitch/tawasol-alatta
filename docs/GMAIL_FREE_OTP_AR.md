# إرسال أكواد تواصل العطا من Gmail مجانًا (بدون دومين)

**مهم:** خادم Cloudflare ينشئ الكود ويحتفظ ببصمته، ويتحقق من انتهاء
صلاحيته (10 دقائق) وعدد المحاولات. Gmail يرسل الرسالة فقط. لا تخزّن كلمة
سر Gmail داخل الموقع أو تطبيق أندرويد ولا في GitHub.

## 1. إنشاء الجسر على Google

1. من حساب Gmail الذي تريد إرسال الأكواد منه، افتح https://script.google.com/
2. اختر New Project واحذف المثال والصق محتوى الملف
   `integrations/gmail-apps-script/Code.gs`.
3. افتح **Project Settings → Script properties**، وأضف الخاصية
   `ATTA_GMAIL_SHARED_SECRET` بقيمة سرية عشوائية قوية (32 حرفًا على الأقل).
4. اختر **Deploy → New deployment → Web app**.
   اختر **Execute as: Me** و**Who has access: Anyone**.
   اسمح للتطبيق بإرسال البريد باستخدام `MailApp`؛ التطبيق لا يقرأ صندوق
   بريدك ولا يحتاج كلمة مرور Gmail.
5. انسخ عنوان Web app المنتهي بـ `/exec`. لا تنشره في شيفرة الواجهة.
   أي شخص يملك العنوان يستطيع الاتصال به، لكن إرسال البريد يتطلب السر الخاص.

## 2. ربط الجسر مع Cloudflare Worker

استخدم نفس قيمة السر في إعدادات Cloudflare، بدون وضعها في GitHub:

```sh
cd cloudflare-site
npx wrangler secret put ATTA_GMAIL_SCRIPT_URL
npx wrangler secret put ATTA_GMAIL_SHARED_SECRET
npx wrangler deploy
```

في السؤال الأول أدخل **رابط Apps Script /exec**، وفي الثاني أدخل
**نفس السر** الموجود في Script Properties.

عند وجود المتغيرين، Gmail يرسل أكواد التسجيل، واستعادة كلمة السر،
وحماية الإدارة. في غيابهما يبقى مسار Resend القديم كما هو. إذا كانت إعدادات
Gmail ناقصة أو رفضت الإرسال، يظهر فشل للمستخدم بدون إرسال مزدوج.

## 3. الاختبار

- جرّب تسجيل حساب اختبار بعنوان بريد مختلف عن بريد المرسل.
- تحقق من وصول رقم من 6 خانات، ثم اكتبه في واجهة تأكيد حساب تواصل العطا.
- اختبر استعادة كلمة السر. لا تعتمد النظام قبل نجاح اختبار فعلي مع بريد المستلم.
- تحقق من مجلد البريد غير المرغوب فيه.
- Gmail الشخصي عبر Google Apps Script يسمح عادةً بـ **100 مستلم يوميًا**
  (الحصة قابلة للتغيير وتخضع لسياسات Google).
- في Google Apps Script → Executions يمكن فحص أخطاء التشغيل بدون كشف
  رموز التحقق أو الأسرار.

لا يتطلب هذا تعديل APK أو إصدارًا جديدًا؛ تحديث Worker فقط. يتطلب أن يُفعّل
صاحب حساب Gmail عملية الإرسال بنفسه ويوافق على الأذونات.
