# تخفيف حجم إصدار 1.0.133

قياس ملف الإصدار المنشور 1.0.129: **174,308,816 بايت**. يشغل المصحف المضمن داخل ZIP مقدار **104,480,418 بايت**؛ وتشغل مكتبات x86 وx86_64 معًا **28,026,948 بايت**. نصوص الترخيص وملفات TXT ليست السبب الأساسي للحجم. لا يُحذف كود المكالمات أو المكتبات اللازمة لها أو قاعدة الأحاديث أو الأذان أو ملفات المستخدمين.

استكمالًا لطلب تحميل الصفحات بعد التثبيت، يحتفظ APK بالفاتحة والفهرس والترخيص. تُنزّل الصفحات 2–604 من نسخة Git ثابتة عند فتحها، وتُحفظ مضغوطة في التخزين الخاص الدائم للتطبيق. لا يعتمد التخزين على مجلد cache القابل للمسح التلقائي. زر **فهرس المصحف ← تنزيل المصحف كاملًا** ينزّل الصفحات الناقصة، مع تقدم وإيقاف واستكمال لاحق دون إعادة تنزيل الصفحات الصحيحة. مجموع تنزيل الصفحات الإضافية **96,406,200 بايت**، ويضاف إلى مساحة الهاتف بعد التنزيل؛ تخفيف APK لا يعني إلغاء مساحة المحتوى المحفوظ.

يُتحقق من حجم كل صفحة وبصمتها قبل تثبيتها بملف مؤقت. التنزيل الجزئي أو التالف يُحذف ويُعاد عند المحاولة، والنسخة الصحيحة تُقرأ دون اتصال. لا يتصل وضع قراءة الصفحات المحفوظة بالشبكة. تبقى المشاركة والصورة وPDF والقارئ على مصدر صفحات واحد. الفاتحة متاحة من أول تشغيل دون تنزيل.

تضم نسخة الإصدار محرك WebRTC لمعمارتي ARM64 وARM32. تبقى مكتبات x86 في debug لاختبارات المحاكي. لم يُفعّل تصغير الكود أو حذف الموارد عشوائيًا؛ التوفير الأساسي من صفحات المصحف ومعماريات المحاكي.

أُصلح فحص النسخة الذي ظل يتوقع 1.0.129 رغم تقدم Gradle إلى 1.0.132، وحددت النسخة الجديدة 1.0.133 / 233. تُفحص حزم direct وAppGallery الفعلية قبل النشر: الفاتحة والفهرس والترخيص، الأحاديث كاملة، الأذان والصلاحيات، وجود محرك المكالمات للمعماريتين، وعدم تجاوز ميزانية 60,000,000 بايت. قياس APK النهائي بعد البناء هو الرقم المعتمد للحجم.

اختبارات تنزيل المصحف تستخدم ملفات الصفحات الأصلية مع نقل شبكي مُحاكى: إعادة الاستخدام دون اتصال، تلف البصمة، نقص البيانات، تجاوز الحجم، تحويل HTTP، فقد الشبكة وإعادة المحاولة، واستعادة النسخة التالفة والصفحة 604. لا تتصل هذه الاختبارات بمصادر خارجية.
