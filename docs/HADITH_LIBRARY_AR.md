# مكتبة الأحاديث العربية

تعرض صفحة الأحاديث الكتب التالية بنصوصها العربية المحفوظة داخل التطبيق:

| الكتاب | عدد السجلات في النسخة المضمنة | النسخة المصدرية |
| --- | ---: | --- |
| الأربعون النووية | 42 | النص العربي في hadith-json / Sunnah.com |
| صحيح البخاري | 7008 | Islamware / Open-Hadith-Data |
| صحيح مسلم | 5362 | Islamware / Open-Hadith-Data، وتشمل روايات المقدمة |
| موطأ مالك | 1594 | Islamware / Open-Hadith-Data |

المجموع 14006 سجلًا. هذه أعداد وترقيم النسخ المصدرية المحددة، وليست ادعاءً بتوحيد أرقام جميع الطبعات. بعض الطبعات تجمع الطرق والروايات أو تفصلها بصورة مختلفة. يحافظ التطبيق على جميع السجلات والنصوص العربية في هذه النسخ دون اختصارها، ويعرض بيان النسخة ومصدرها. لا يضم ترجمات حديثة أو شروح العمود الثالث من ملفات المصدر.

## القراءة والبحث

- اختر الكتاب ثم اقرأه كاملًا، أو افتح مجموعة من فهرس القراءة. كل مجموعة تصل إلى 100 حديث؛ هذه مجموعات للتصفح وليست أسماء الأبواب الأصلية للكتاب.
- البحث من خانة البحث الموجودة في شريط التطبيق. في البداية يبحث في الكتب الأربعة، وداخل الكتاب يبحث في الكتاب كله حتى عند فتح مجموعة قراءة.
- يعمل البحث بالكلمات دون اشتراط التشكيل أو شكل الهمزة، وبالأرقام العربية والإنجليزية والفارسية. البحث الرقمي يستخدم ترقيم النسخة المضمنة.
- يعرض القارئ 12 حديثًا في كل صفحة، بنصوص كاملة قابلة للتحديد والنسخ والمشاركة. يمكن تغيير حجم الخط وحفظ موضع للعودة إليه بعد إغلاق التطبيق.
- يدعم الفهرس الانتقال مباشرة إلى رقم حديث، كما يدعم القارئ أول صفحة وآخر صفحة والصفحتين السابقة والتالية.
- تعرض نافذة المصادر اسم المصدر والترقيم ورابط النسخة. لا يوجد مربع بحث إضافي أو مشغل أو صفحة ويب بديلة عن القارئ الأصلي.

## التشغيل دون اتصال وسلامة البيانات

البيانات مضمنة بحجم مضغوط 7807153 بايت (نحو 7.8 ميجابايت). عند الفتح الأول يفك التطبيق قاعدة SQLite إلى مساحة التطبيق الخاصة بحجم 37335040 بايت، ثم يستخدمها مباشرة دون تحميل الكتب كاملة إلى ذاكرة الواجهة أو طلبها من الشبكة. يتطلب الفتح الأول مساحة مؤقتة تكفي القاعدة؛ تظهر رسالة مع إعادة المحاولة عند تعذر تجهيزها.

تُفحص بصمة SHA-256 وحجم القاعدة قبل تثبيتها، مع فحص بنية SQLite وعدد السجلات. النسخة الجديدة تُثبت عبر ملف مؤقت. ملفات البيانات المضغوطة مقسمة إلى أجزاء صغيرة يُقرأ مجموعها كتدفق gzip واحد. يفحص بناء APK تضمين كل جزء وصحته مع ملف المصادر والإشعارات.

مصادر البيانات مثبتة بإصدارات Git محددة وروابطها وبصماتها في `android-native/app/src/main/assets/hadith/manifest.json`. يمكن إعادة بنائها بالأمر:

```sh
python3 scripts/build_hadith_library.py --source-dir /tmp/alatta-hadith-sources --download
python3 scripts/test_hadith_library.py
```

إصدار Open-Hadith-Data هو `1515f6cba21efed20d8916bf55acef1dffa0d2d5`، وإصدار hadith-json هو `ca32fd72aa16eeeb9a819c80bb65c9e78766532d`. قاعدة البيانات المشتقة متاحة وفق ODbL 1.0، مع بيانات الإسناد والتحويلات وروابط ODbL وDbCL في `NOTICE.txt`. يبقى النص العربي المطبوع مشكولًا؛ التطبيع خاص بفهرس البحث فقط.

تتحقق الاختبارات من النص الكامل لكل سجل وبصمته، وعدم وجود فراغات أو أرقام مفقودة، وأول وآخر رواية في كل كتاب، ومطابقة البحث المفهرس للبحث المباشر في كامل النص، وحدود فهرس القراءة والصفحة الأخيرة. اختبارات Kotlin تغطي تطبيع البحث وأمان عباراته والأرقام العربية والفارسية. التحقق من تجميع نسختي Android وAppGallery لا يغني عن تجربة القراءة على جهاز فعلي.
