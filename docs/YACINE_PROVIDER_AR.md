# ربط ياسين التجريبي — 1.0.173 / 273

يضيف تبويب «ياسين» داخل صفحة الرياضة محاولة جلب الأقسام والقنوات والبحث وبيانات تشغيل القناة، ثم يمرر مصادر HLS وDASH وMP4 المدعومة إلى مشغّل العطا الموجود. لا يحتاج المستخدم إلى تثبيت ياسين أو YTV PRO.

البدء اختياري بزر «تحميل قنوات ياسين». القوائم المعروضة تأتي من استجابة المصدر؛ لا توجد قنوات تجريبية أو روابط وهمية. يستخدم مسارات الأقسام والبحث من عنوان القائمة القديم الموجود داخل APK ياسين، ومسار `channel/{id}` من عنوان المشغّل القديم الموجود داخل APK YTV PRO، عبر HTTPS. لا يُعتبر توفر أيٍّ منهما مثبتًا. قيمة عنوان الخادم البعيد الحالية لم تتوفر أثناء التطوير، وقد تختلف عن هذه العناوين.

يدعم الربط ردود JSON المباشرة. عندما يرفض المصدر الاتصال، أو يغيّر عنوانه، أو يعيد صفحة ويب أو بيانات مشفرة/غير متوافقة أو مصدرًا غير مدعوم، تظهر رسالة توضح المرحلة والمشكلة مع زر إعادة المحاولة. لا تُعرض أجسام ردود الخادم أو روابطه الخاصة في رسالة الخطأ. لا يفتح الرد موقعًا بديلًا أو تطبيقًا خارجيًا، ولا يتجاوز رفض الوصول.

تبقى سياسة HTTPS الموجودة كما هي. تدعم مصادر التشغيل User-Agent وReferer وOrigin بعد التحقق منها، ويُعزل كل مصدر عن إعدادات المشغّلات الأخرى وعن التخزين المؤقت المشترك. المصادر التي تحتاج DRM أو ترويسات أخرى تظهر كغير مدعومة. تُوقف محاولة جلب البث والمشاهدة الجديدة عند وجود مكالمة.

تغطي اختبارات MockWebServer المسارات وفصل خادم القائمة عن التشغيل، ترميز البحث، حالات رفض HTTP، الردود غير المتوافقة، التحويلات، حدود الحجم، المصادر والترويسات غير المقبولة، وإلغاء الطلبات. تغطي اختبارات النقل عزل ترويسات المصدر وعدم تخزينها مع الوسائط العامة. لا تتصل الاختبارات بالمزوّد الحقيقي.

نجاح البناء والاختبارات لا يثبت نجاح بث ياسين الحي. في بيئة التطوير حُجبت محاولات الاتصال بالمصادر القديمة بردود 403 و436؛ يلزم اختبار الاتصال والمشاهدة على جهاز فعلي قبل وصف الربط بأنه يعمل.
