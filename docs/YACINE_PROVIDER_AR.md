تسمح إعدادات أندرويد باتصال HTTP إلى `def001.ycnapi.com` وحده دون النطاقات الفرعية، مع منعه افتراضيًا لكل الوجهات الأخرى. هذا الاتصال غير مشفّر، ويقتصر استخدامه على طلب بيانات المشغّل دون إرسال حساب العطا أو رموزه أو ملفاته. طلب القوائم وروابط الوسائط المدعومة تبقى عبر HTTPS، ولا يتبع عميل المصدر التحويلات. تدعم مصادر التشغيل User-Agent وReferer وOrigin بعد التحقق منها، ويُعزل كل مصدر عن إعدادات المشغّلات الأخرى وعن التخزين المؤقت المشترك. المصادر التي تحتاج DRM أو ترويسات أخرى تظهر كغير مدعومة. تُوقف محاولة جلب البث والمشاهدة الجديدة عند وجود مكالمة.
