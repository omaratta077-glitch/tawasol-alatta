# تفعيل بريڤو المجاني لتواصل العطا (بدون دومين خاص)

خادم Cloudflare يستخدم **Brevo أولًا** عند توفر متغير `BREVO_API_KEY`،
ثم يستخدم مزود Resend الموجود إذا كان مفتاح Brevo **غير موجود** فقط.
إذا فشل إرسال Brevo لن يعيد إرسال نفس الكود عبر Resend تلقائيًا؛ منعًا
لتكرار الرسائل أو تضارب الأكواد.

## خطوات تخص صاحب حساب Brevo / Cloudflare

1. افتح https://www.brevo.com/ وأنشئ حسابًا مجانيًا؛ الباقة محدودة بـ300 رسالة يوميًا.
2. في Brevo افتح **Settings → Senders, Domains & Dedicated IPs → Senders**،
   أضف عنوان بريد تملكه، بالاسم «تواصل العطا»، ثم أدخل كود تأكيد المرسل.
   لا يتطلب ذلك شراء دومين للتجربة، **لكن** Brevo قد يستبدل عنوان Gmail
   بعنوان إرسال تابع لها وقد تتأثر قابلية التسليم.
3. من **Settings → SMTP & API → API Keys** أنشئ مفتاح API.
4. احفظ إعدادات Cloudflare بأمان (لا ترسل المفتاح في محادثة، ولا تضعه في GitHub):
   ```sh
   cd cloudflare-site
   npx wrangler secret put BREVO_API_KEY
   npx wrangler secret put BREVO_SENDER_EMAIL
   ```
   أدخل قيمة مفتاح Brevo في الخطوة الأولى والبريد الموثق في الثانية؛
   اسم المرسل الافتراضي «تواصل العطا» ولا يحتاج إعدادًا إضافيًا.
5. انشر الـWorker بالأمر المعتاد `npx wrangler deploy`، ثم اختبر
   إنشاء حساب تجريبي واستعادة كلمة المرور في بريد حقيقي.
6. إذا ظهر `EMAIL_SEND_FAILED` فتأكد من حالة تفعيل Transactional Email
   وصحة sender في Brevo، ومن حدود الباقة، قبل محاولة إعادة الإرسال.

**تنبيه:** التعديل على كود GitHub لا يفعّل إرسالًا حقيقيًا وحده:
يلزم ربط حساب Brevo وضبط المتغيرات السرية ونشر Worker.
لم يتغير Android APK أو توقيعه أو رقم الإصدار.
