# تواصل العطا 1.0.78 / Build 178 — تغيير حساب المدير

إذا نسيت كلمة مرور حساب المدير القديم، يمكنك تعيين حساب آخر تملك إمكانية الدخول إليه، من إعدادات نفس Worker في Cloudflare.

1. أنشئ حسابًا عاديًا جديدًا داخل تطبيق تواصل العطا أو الموقع، أو استخدم حسابًا آخر مسجلًا تعرف كلمة مروره.
2. في Cloudflare: Workers & Pages ثم tawasol-alatta ثم Settings ثم Variables and Secrets.
3. حدّث SUPER_ADMIN_USERNAME باسم المستخدم الجديد، و SUPER_ADMIN_EMAIL بنفس البريد المسجل في ذلك الحساب. احفظ عبر Deploy.
4. ادخل التطبيق بالحساب الجديد؛ سيأخذ صلاحية المدير. المدير القديم يفقد صلاحيات الإدارة على الخادم.

لا تكتب كلمة المرور في متغيرات Cloudflare. تغيير المدير لا يحتاج معرفة كلمة مرور المدير القديم، لكنه يتطلب أن تكون مالك إعدادات Worker وأن تملك الحساب الجديد وبريده.

الإصدار 1.0.78 يزيل قيد omar1 الثابت من مسار التصفير والرسائل وأداة المعاينة، ويستخدم إعدادات المدير الحالية. نُفّذ اختبار تبديل المدير إلى اسم آخر والتحقق من سحب صلاحية السابق وإتاحة التصفير للمدير الجديد.

إذا كان هدفك تنفيذ التصفير، انشر Worker هذا الإصدار أولًا، ثم استخدم لوحة المدير بالحساب الجديد. بقية تعليمات التصفير والإخفاء موضحة في README_V177_FULL_RESET_PRIVACY_AR.md؛ اسم omar1 الوارد فيه مثال تاريخي ويستبدل باسم المدير الحالي. التصفير نفسه ما زال يحذف جميع الحسابات بما فيها حساب المدير الحالي ولا ينشئ نسخة احتياطية.

لم يتم تغيير إعدادات Cloudflare الفعلية أو تنفيذ حذف إنتاجي في هذه الجلسة. هذه حزمة مشروع مصدر؛ APK 1.0.78 / 178 يحتاج البناء عبر Workflow الحالي، الذي ينتج tawasol-alatta-v1.0.78.apk. لم تُبنَ حزمة APK هنا لعدم توفر Android SDK والتوقيع.
