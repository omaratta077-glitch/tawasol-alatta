# تطبيق Tawasol Al-Atta v1.0.30

هذا تعديل لمشروع Android الأصلي (Kotlin/Jetpack Compose) وليس ملفات الموقع.

* شاشة استكشاف: بحث عن الأشخاص والمنشورات وعرض النتائج.
* الضغط على صورة واسم صاحب المنشور يفتح ملفه الشخصي.
* إظهار المنشورات المؤرشفة ضمن واجهة API الحالية بدون حد 50 منشورًا (قد يتطلب إكمال الدعم بالخادم لأي سجل خارج الفهرس).
* أسماء التعليقات من الملف الشخصي عند توفرها، والنص أبيض.
* زيادة مساحة AL-ATTA بجانب اللوجو.
* رقم البناء 130 والإصدار 1.0.30.

التحقق محلي بالشفرة فقط؛ لم يُنفّذ بناء APK فعلي هنا. يلزم اختبار GitHub Actions والتطبيق على الهاتف.
