# بدء تشغيل القنوات وتقرير المشغّل — 1.0.193

ظهر على هاتف المالك مشغّل أسود وتقرير بلا أحداث أو وقت انتظار؛ لا يثبت ذلك وحده هل جرى النسخ مبكرًا أم تعلّق تجهيز المشغّل. تبدأ المهلة الآن عند اختيار المصدر، فتغطي تجهيز الاتصال والمشغّل وتحميل الوسائط. ينتقل الاختبار بعد 20 ثانية إلى الخيار التالي إذا لم يبدأ التشغيل، ويتوقف بعد نفاد الخيارات.

يحسب زر «نسخ نتيجة التجربة» التقرير لحظة الضغط، ويظل متاحًا أثناء تجهيز المشغّل. يعرض الوقت المنقضي، ومراحل تجهيز النقل والمشغّل، وحالة Media3 والتحميل وطلب التشغيل وحجم الفيديو، بالإضافة إلى أخطاء HTTP/المشغّل الرقمية. يسجل بداية كل محاولة؛ لا ينسخ روابط البث أو قيم الترويسات. لا يمرّر رابط الفيديو إلى عارض الصور أثناء تهيئة Media3. التحديث لا يغيّر قارئ المصدر أو المزامنة المستقلة أو التبويبات.

يتضمن اختبار أندرويد تشغيل مشغّل Media3 الموجود مع نقل تجريبي يتوقف داخل القراءة دون أي اتصال شبكي. يتحقق الاختبار من طلب التشغيل، والانتقال بين مصدرين، وانتهاء المهلة، وحداثة التقرير المنسوخ وإخفاء الروابط وقيم الترويسات. نجاحه لا يثبت قبول مزود البث للطلبات الحقيقية؛ ذلك يتأكد من تقرير هاتف المالك.

الإصدار 1.0.193، رقم البناء 293، وملف التحديث `tawasol-alatta-v1.0.193.apk` بالتوقيع الرسمي.
