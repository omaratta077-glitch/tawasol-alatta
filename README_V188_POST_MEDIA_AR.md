# تواصل العطا 1.0.88 — الصور والفيديو والتفاعلات

إصدار Android `1.0.88`، ورقم البناء `188`، واسم APK الرسمي الناتج من GitHub Actions: `tawasol-alatta-v1.0.88.apk`. هذا هو المشروع الكامل المبني على الملف المرسل `tawasol-alatta-main (4).zip`، بإضافة تعديلات الصور والفيديو والتفاعلات. حُفظت ملفات المصدر الأخرى وصفحات المصحف، وأُكمل تعريف حساب الحزب الناقص في قارئ القرآن لنجاح البناء.

## الصور والفيديو

- يفتح الضغط على صورة المنشور عرضًا بملء الشاشة. أزيل شريط العنوان والإغلاق وأزرار التصغير والملاءمة والتكبير. يمكن التكبير بإصبعين أو بالنقر مرتين، والضغط مرة يبدّل ظهور التفاعلات.
- عدد التفاعلات يفتح أسماء أصحابها وصورهم ونوع التفاعل، والاسم يفتح الملف الشخصي. التعليقات تُفتح وتُرسل من عرض الصورة أو الفيديو.
- يفتح الضغط على معاينة الفيديو العارض نفسه، ثم يبدأ بزر تشغيل واحد. لا توجد أشرطة بعنوان الفيديو أو أزرار تكبير وملاءمة أو تحكم Media3 المكرر. يظهر تشغيل/إيقاف مؤقت وشريط تقدم عند الطلب، وتختفي الأدوات أثناء التشغيل.
- السحب لأعلى يفتح الفيديو التالي من نفس قائمة المنشورات المحمّلة، والسحب لأسفل يعيد السابق. تتجاوز القائمة منشورات النصوص والصور. إذا كان الفيديو يعمل، يستمر التشغيل عند الانتقال؛ وإذا كان متوقفًا، يظل التالي متوقفًا حتى يختار المستخدم تشغيله.
- الرجوع في الهاتف يغلق قائمة التعليقات/التفاعلات أولًا، ثم يعيد المستخدم للمنشورات. يتوقف الفيديو ويُحرّر المشغّل عند إغلاق العارض، ويتوقف عند انتقال التطبيق إلى الخلفية. تُغلق الوسائط عند وصول مكالمة لتظهر واجهة الرد.
- ينشئ عارض أندرويد مشغّل Media3 واحدًا لقائمة الفيديو كلها. معاينات المنشورات لا تنشئ مشغّلًا لكل بطاقة. ما زال مشغّل YouTube مستقلًا كما كان.
- يحافظ العرض على نسبة أبعاد الوسائط دون قص أجزاء منها. قد تظهر مساحة سوداء حول فيديو أفقي عند وضع الهاتف رأسيًا.

تعمل نقاط فتح الوسائط في الرئيسية والاستكشاف ومنشورات المستخدم والملف الشخصي العام. عرض الصورة الشخصية والغلاف يستخدم العارض ذاته. على الموقع، يفتح المتصفح ملء الشاشة إذا سمح به؛ ويظل عرض الوسائط يغطي مساحة الصفحة إذا لم يدعم المتصفح واجهة ملء الشاشة. يعمل Escape والرجوع، ويدعم الفيديو السحب ولوحة المفاتيح.

## الأسماء والعدّ والخصوصية

أضيف مسار واحد: `GET /api/post-interactions`، بمعاملات `token` و`postId` و`kind` (`reactions` أو `comments`) و`offset`، مع حد أقصى ٥٠ عنصرًا في الطلب. تستخدمه واجهتا أندرويد والموقع. قائمة التفاعلات والتعليقات تدعم تحميل المزيد.

تخضع النتائج لسياسة ظهور المنشور والحساب الحالية، وتستبعد من لا يجوز للمشاهد رؤيتهم، بما في ذلك الحسابات المخفية والمحظورة والمعطّلة. يعيد المسار الاسم العام والصورة فقط، ولا يعيد البريد أو بيانات الدخول. لا يغيّر فتح قائمة التفاعلات أي إعجاب.

دُمجت الإعجابات القديمة والتفاعلات الحديثة عند العدّ، بحيث يُحسب الشخص مرة واحدة. تبديل نوع التفاعل يزيل تفاعله القديم وإعجابه القديم، وتظهر الأرقام الجديدة في المنشور وعرض الوسائط. أُصلح في الموقع إطلاق الإعجاب العادي بعد الضغط المطوّل على زر التفاعل.

## النشر والتحقق

يحتاج هذا الإصدار نشر محتويات `cloudflare-site` إلى **نفس Worker الحالي**، ثم بناء APK بالتوقيع الرسمي الحالي. تحميل ZIP وحده لا يعدّل التطبيق المثبّت أو Cloudflare. يجب نشر Worker قبل استخدام APK الجديد لتعمل قائمة الأسماء والتعليقات الجديدة. لا تغيّر نطاق الخادم أو مفاتيح Google أو Firebase أو TURN أو بيانات المدير.

شغّل `python3 scripts/check_core.py` وجميع اختبارات `scripts/*.mjs`. أضيف اختبار API للتفاعلات إلى مساري التحقق وبناء الإصدار الرسمي. الاختبارات تستخدم بيانات محلية، ولا تعدّل مستخدمين أو منشورات فعلية.

تظل ملفات صفحات المصحف وأحدث قارئ القرآن 1.0.86، ووظائف الإدارة والقصص والخصوصية والمكالمات وGoogle وYouTube محفوظة. لا توجد تسجيلات قراء جديدة أو نسخ إضافية من المصحف في هذا الإصدار.

## التحقق المنفذ لهذه النسخة

نجح فحص المصدر `scripts/check_core.py` وجميع اختبارات Node العشرين، بما فيها التفاعلات والخصوصية والإدارة والمكالمات والقرآن وYouTube. اختُبرت الواجهة في Chromium بأبعاد 390×844 و1440×960، مع تشغيل MP4 فعلي، والسحب باللمس بين الفيديوهات، وفتح أسماء المتفاعلين دون تغيير الإعجاب، وإرسال تعليق، والرجوع من القائمة ثم العارض وإيقاف الفيديو. بيانات الاختبار محلية.

نجح بناء Android كاملًا بواسطة `:app:assembleDebug` للإصدار 1.0.88 ورقم البناء 188. جرى التحقق من وجود عارض الوسائط وقائمة التفاعلات في APK، ومطابقة صفحات المصحف الـ604 وملف الفهرس والترخيص داخله. بقيت ملفات صفحات المصحف وملف ربط YouTube مطابقة للملف المرسل. عُدّل فحص GitHub ليتوافق مع الاستدعاء الجديد لمشغّل الفيديو.

هذه اختبارات متصفح وتجميع؛ لم تُجرَ تجربة على هاتف Android فعلي. يحتوي ZIP على المصدر الكامل، ويُبنى APK الرسمي من مسار GitHub الحالي بالتوقيع نفسه. يجب نشر Worker وملفات الموقع لتفعيل واجهة التفاعلات الجديدة.
