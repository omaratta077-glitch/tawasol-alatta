# تواصل العطا v1.0.57 — بناء 157

## السبب الذي عالجناه
في v1.0.56 كان Android WebView يفتح الصفحة الرئيسية ثم يمسح DOM بالكامل (`document.body.replaceChildren`) وينشئ إطارًا جديدًا. هذا ليس نفس تشغيل مشغل Chrome، وقد كان اختبار المصدر يوافق على هذا السلوك رغم ظهور الشاشة السوداء.

## التغيير
- التطبيق يُحمّل الصفحة الفعلية `$BASE/` ويضغط زر YouTube في **الموقع نفسه** ثم يرسل رابط الفيديو عبر نموذج بحث الموقع؛ لذلك ينشئ الموقع الـ iframe الوحيد بواسطة `youtube-section.js` / `youtube-player-shared.js`.
- أزيل من أندرويد كود إنشاء iframe، ونسخ نسخة أخرى من مصنع YouTube داخل APK.
- `atta-site-youtube-bridge.js` جسر واجهة وتشخيص فقط، ولا ينشئ مشغلًا.
- لا تغيير في الموقع أو Google أو المكالمات أو التوقيع. إصدار Android أصبح 1.0.57/157.
- لو استمرت الشاشة السوداء، بعد 20 ثانية سيظهر زر **نسخ تقرير المشكلة**؛ انسخه وأرسله للمراجعة. يحتوي إصدار Android ومزوّد WebView ومعرّف فيديو عام وآخر حدث، دون رموز دخول.

## حدود الاختبار
فحوص المصدر والـ JavaScript لا تثبت نجاح تشغيل YouTube على HONOR. لا توجد بيئة Android SDK أو هاتف فعلي هنا. لا تقل إن المشكلة انتهت قبل اختبار APK.

## تجربة مهمة
بعد رفع المشروع وبناء APK من GitHub Actions، اختبر فيديو محددًا يعمل في Chrome. لو فشل، انتظر 20 ثانية، اضغط نسخ تقرير المشكلة وأرسله. إذا لم يكن مشغل YouTube الموجود على الموقع منشورًا في Cloudflare فلن تعمل هذه الطريقة أيضًا.
