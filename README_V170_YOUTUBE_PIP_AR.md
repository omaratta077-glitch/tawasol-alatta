# تواصل العطا — 1.0.170 (Build 270)

## استمرار تشغيل فيديو يوتيوب

- يظل مشغل يوتيوب الرسمي نفسه ظاهرًا في نافذة مصغّرة عند التنقل بين صفحات التطبيق.
- يمكن سحب مقبض النافذة لنقلها إلى موضع مناسب داخل الشاشة.
- عند مغادرة التطبيق أثناء تشغيل الفيديو، ينتقل المشغل إلى نافذة Android العائمة (Picture-in-Picture) بنسبة 16:9. يظل الفيديو ظاهرًا ويمكن تحريك النافذة أو إعادتها للتطبيق.
- فيديو يوتيوب داخل منشور يستخدم المشغل المصغّر نفسه بدل إنشاء مشغل WebView ثانٍ.
- يبقى تحميل وتشغيل الفيديو عبر مشغل YouTube الرسمي الموجود على موقع تواصل العطا؛ لا يجري استخراج رابط الفيديو أو فصل الصوت عنه.

## حدود التشغيل

سياسات YouTube API تمنع تشغيل محتوى YouTube من مشغل مخفي لا يظهر للمستخدم. لذلك يبقى الفيديو ظاهرًا أثناء التنقل داخل التطبيق أو في نافذة PiP؛ ولا نفعّل تشغيلًا صوتيًا مخفيًا مع إطفاء الشاشة.

## التحقق

- فحوصات `scripts/check_core.py` و`node scripts/test_youtube_single_origin.mjs` و`node scripts/verify_sources.mjs`.
- يتطلب التحقق النهائي بناء Android واختبار PiP على جهاز يدعم Android 8.0 أو أحدث.
