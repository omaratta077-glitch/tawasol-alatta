# تواصل العطا 1.0.58 — اقتراحات يوتيوب وتحسين الشاشة

## النسخة المرجعية المحمية
- إصدار 1.0.57 هو المرجع الذي أكد المستخدم أن الفيديو يعمل فيه. ملف APK v1.0.57 القديم لا يتم تعديله.
- **ملف الجسر `atta-site-youtube-bridge.js` لم يتغير نهائيًا.**
- **مصنع iframe بالموقع `youtube-player-shared.js` لم يتغير نهائيًا.**
- بداية تشغيل Android WebView وتكوين المشغل الواحد داخل `YouTubePlayer()` لم تتغير.
- كود تشغيل المشغل بالموقع (`function play(id)`) لم يتغير.

## التغييرات
1. عند فتح YouTube تُجلب فيديوهات تلاوة القرآن الكريم بدل الفيديوهات الرائجة العامة؛ وكذلك الطلب بدون q من موقع الويب.
2. أقسام اقتراحات: قرآن / أحاديث / رياضة (كرة القدم فقط) / أخبار. نتائج البحث قائمة على YouTube Data API ولا تعني توثيقًا شرعيًا لمحتواها.
3. الضغط على مقطع من النتائج لا يبدأ تشغيله؛ يظهر في أعلى القائمة بصورة معاينة وزر «▶ تشغيل الفيديو».
4. الضغط على الزر هو وحده الذي ينشئ المشغّل الناجح من v1.0.57. اختيار فيديو مختلف يوقف مشغل الفيديو السابق ويظهر معاينة جديدة.
5. لا يوجد زر «ملء الشاشة» الخاص بالتطبيق ولا «فتح في YouTube» ولا شريط أزرار تحت الفيديو. أخطاء المشغّل تظهر داخل مساحة الفيديو عند حدوثها فقط.
6. لا تعديل على تسجيل Google أو المكالمات أو التوقيع أو ملفات Firebase.

## مهم بعد الرفع
- يجب نشر تعديل `/api/youtube` على Cloudflare لكي يرى زوّار الموقع أيضًا القرآن تلقائيًا.
- على أندرويد قسم «قرآن» يعتمد على `q` صريح، فيعمل مع الخادم القديم أيضًا.
- كل فحص مصدر لا يعوّض عن بناء APK وتجربة فعلية على HONOR؛ اختبر فيديو معروفًا أنه يعمل في 1.0.57 بعد التثبيت.
