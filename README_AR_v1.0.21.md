# تواصل العطا — تحديث 1.0.21

## الجديد
- الضغط على الصورة الشخصية أو الغلاف أو صورة المنشور يفتح عارضًا ملء الشاشة؛ تكبير باللمس أو بالأزرار وتصغير وملاءمة.
- صور المنشورات تملأ عرض البطاقة بنسبة ثابتة، والضغط يعرض الصورة كاملة دون اقتصاص.
- أزرار تغيير الصورة الشخصية والغلاف صغيرة (34dp) في صفحة الحساب.
- إضافة البلد والمدينة والتعليم والعمل والنبذة في صفحة الحساب، وتظهر للأصدقاء بعد الحفظ وتحديث خادم Cloudflare.
- التفاعل المختار يظهر على زر القلب، ويُسترجع من الخادم بعد التحديث. تحديث الخادم يضمن ألا يتكرر إعجاب عادي وتفاعل مخصص لنفس المستخدم.
- عنصر «فحص تحديث التطبيق» في القائمة مع رسالة واضحة عن الإصدار المتاح أو مشكلة الفحص.

## مهم: رفع فرع main
1. من حزمة PATCH، انسخ الملفات إلى المسارات المذكورة داخل ZIP على فرع main. لا تضع المجلدات داخل مجلد جديد.
2. Android: ارفع مجلد `android-native` بجميع مساراته، ثم Commit.
3. Cloudflare: ارفع `cloudflare-site/src/worker.js` إلى نفس المسار. يلزم **نشر Worker في Cloudflare** لتعمل حقول الملف الشخصي والتفاعلات المتزامنة. GitHub Commit وحده لا يضمن النشر.
4. شغّل `Build AL-ATTA Official Release APK` على main وتحقق من ظهور `v1.0.21` في GitHub Releases وفي Assets ملف `tawasol-alatta-v1.0.21.apk`.
5. افتح التطبيق القديم أو اختر «القائمة > فحص تحديث التطبيق»، ثم أكمل التثبيت بموافقة أندرويد.

## التحقق
- فحص نحو JavaScript: `node --check cloudflare-site/src/worker.js` اجتاز.
- فحص رقم Gradle والتطابق بين الحقول الأساسية اجتاز.
- APK لم يُبنَ محليًا ولم يُجرّب على هاتف؛ نجاح GitHub Actions ثم اختبار الهاتف ضروريان.
- لا حاجة إلى تغيير مفتاح التوقيع أو Google OAuth.
