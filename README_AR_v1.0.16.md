# تواصل العطا v1.0.16 — إصلاح شاشة المكالمات السوداء

## المشكلة
في إصدار 1.0.15 كانت شاشة الاتصال مرسومة بالكامل داخل WebView. عندما يتعطل رسم صفحة WebView يظهر مكانها سواد كامل، بما فيه اختفاء الأزرار وزر إنهاء الاتصال.

## الإصلاح
- عرض الاسم والصورة والحالة وأزرار المكالمة باستخدام Android Jetpack Compose مباشرة، بدون الاعتماد على ظهور WebView.
- الاحتفاظ بمحرك WebRTC والإشارات الحالي داخل WebView خلف الواجهة الأصلية.
- بدء تحميل صفحة المحرك بعد إضافة WebView إلى واجهة أندرويد، بدلًا من بدء التحميل مبكرًا.
- تحديث حالة الاتصال التي يعرضها Android عبر JavaScript bridge.
- عرض فيديو الطرف الآخر داخل المنتصف عند تشغيله؛ عناصر التحكم تبقى في Android.
- جلب الاسم الظاهر والصورة من بيانات الملف الشخصي وعدم إظهار معرف الإشارة/اسم المستخدم التقني.
- زر إنهاء المكالمة يبقى متاحًا حتى لو فشل محرك الاتصال، ويعيد وضع الصوت السابق عند إغلاق الشاشة.
- الإصدار الجديد: versionCode 116 / versionName 1.0.16.

## الرفع على GitHub
1. افتح المستودع على فرع main.
2. فك ضغط الأرشيف وارفع الملفات الثلاثة داخل مساراتها كما في الأرشيف (استبدال الملفات القديمة)، من غير إضافة مجلد android-native داخل android-native.
3. Commit changes على main.
4. شغّل workflow: Build AL-ATTA Official Release APK.
5. بعد نجاح البناء والنشر، جرّب التحديث من داخل التطبيق.

## اختبار مقترح
- إجراء اتصال صوتي: لازم تظهر صورة دائرية/اسم/حالة/أزرار حتى لو لم يتم الاتصال.
- الضغط على زر إنهاء الاتصال: الخروج من الشاشة بلا تعليق.
- تجربة اتصال صوتي من الهاتف إلى الموقع والعكس مع سماع صوت من الجهتين.
- تجربة مكالمة فيديو، ظهور الفيديو والعودة من المكالمة بصورة سليمة.

## ملاحظات
هذا إصلاح لواجهة العرض وبعض توقيت تحميل محرك WebRTC، وليس إثباتًا بأن جميع أعطال اتصال الصوت والإنترنت أو صلاحيات الميكروفون قد انتهت. يلزم بناء APK وتجربته على هاتف؛ لم تتوفر بيئة Android SDK للبناء داخل هذه الجلسة.
لا تغيّر KEYSTORE أو SHA-1 أو إعدادات Google/Cloudflare. لا توجد حاجة لنشر خادم جديد لهذا التصحيح.
