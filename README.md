# تواصل العطا — الإصدار الحالي 1.0.80

المشروع الكامل لتطبيق Android وموقعه وخادم Cloudflare. تفاصيل الإصدار الحالي في [صفحات المصحف بالرسم الثابت](README_V180_MADANI_MUSHAF_AR.md).

- Android: `android-native/`، الحزمة `com.alatta.nativeapp`، رقم البناء `180`، والإصدار `1.0.80`.
- القرآن: ٦٠٤ صفحات مصحف مرسومة محليًا بسطور ثابتة، وخلفية ورقية وأدوات بنية، مع الفهرس والعلامة والتكبير والتلاوة والتفسير.
- الموقع: `cloudflare-site/public/`، والخادم: `cloudflare-site/src/worker.js`.
- الإدارة والقصص والاتصال المرئي مستمرة كما في [الإصدار السابق](README_V179_ADMIN_QURAN_VIDEO_STORIES_AR.md).

تعليمات تغيير حساب المالك في [دليل المدير](README_V178_CHANGE_ADMIN_AR.md)، والتصفير الشامل في [دليل التصفير](README_V177_FULL_RESET_PRIVACY_AR.md).

ملف ZIP هو شيفرة المشروع؛ بناء APK الرسمي ونشر Worker يتمان من الحساب والمستودع الحاليين. للتحقق: `python3 scripts/check_core.py` ثم اختبارات Node في `scripts/`. لا تُجري الاختبارات حذفًا فعليًا على الخادم.
