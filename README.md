# تواصل العطا — الإصدار الحالي 1.0.88

المشروع الكامل لتطبيق Android وموقعه وخادم Cloudflare. تفاصيل الإصدار في [الصور والفيديو والتفاعلات](README_V188_POST_MEDIA_AR.md).

- Android: `android-native/`، الحزمة `com.alatta.nativeapp`، ورقم البناء `188`.
- صور وفيديو بملء الشاشة، مع الرجوع بزر الهاتف والسحب بين فيديوهات نفس القائمة.
- قائمة أصحاب التفاعلات بالأسماء والصور، وتعليقات داخل عرض الوسائط، مع مراعاة الخصوصية وإزالة التكرار من العدّ.
- قارئ القرآن يحتوي تصحيحات النسخة 1.0.86. بقية وظائف التطبيق مستمرة.
- الموقع: `cloudflare-site/public/`، والخادم: `cloudflare-site/src/worker.js`، بإصدار `13.88.0`.

لتفعيل التحديث، انشر Worker ومحتويات الموقع المرفقة إلى الحساب الحالي، ثم ابنِ APK من GitHub Actions بالتوقيع الرسمي الحالي. الملف مشروع كامل وليس APK موقّعًا، ولا ينفذ نشرًا أو حذفًا فعليًا بمجرد تنزيله.
