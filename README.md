# تواصل العطا — الإصدار الحالي 1.0.79

المشروع الكامل لتطبيق Android الرسمي وموقعه وخادم Cloudflare. تفاصيل هذا الإصدار في [الإدارة والقرآن والاتصال والقصص](README_V179_ADMIN_QURAN_VIDEO_STORIES_AR.md).

- Android: `android-native/`، الحزمة `com.alatta.nativeapp`، رقم البناء `179`.
- الموقع: `cloudflare-site/public/`، والخادم: `cloudflare-site/src/worker.js`.
- إحصائيات الإدارة والحظر والتعطيل وإعادة التفعيل والحذف النهائي للحسابات.
- قارئ قرآن بخط مرفق وتحكم في الوضوح، وتحسين مسار إشارات وحمل الاتصال المرئي.
- القصص في أعلى صفحة الرسائل فقط بدل صف الأصدقاء.

تظل إعدادات المدير ونظام التوقيع الرسمي وGoogle وYouTube وFirebase وTURN الموجودة في المشروع محفوظة. تعليمات تغيير حساب المالك في [دليل المدير](README_V178_CHANGE_ADMIN_AR.md)، والتصفير الشامل في [دليل التصفير](README_V177_FULL_RESET_PRIVACY_AR.md).

ملف ZIP هو شيفرة المشروع؛ نشر Worker وبناء APK الرسمي يتمان من الحساب والمستودع الحاليين. للتحقق: `python3 scripts/check_core.py` ثم اختبارات Node في `scripts/`. لا تُجري الاختبارات حذفًا فعليًا على الخادم.
