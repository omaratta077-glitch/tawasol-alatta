# تواصل العطا — المشروع الأساسي المنظّم

المسار الرسمي لتطبيق أندرويد: `android-native/` (اسم الحزمة `com.alatta.nativeapp`).

الموقع والخادم: `cloudflare-site/public/` و`cloudflare-site/src/worker.js`؛ النشر يستخدم `cloudflare-site/wrangler.toml`.

ملف البناء والتوقيع الرسمي: `.github/workflows/build-native-release.yml`. **مفاتيح التوقيع الأربعة محفوظة في GitHub Secrets؛ لا تنسخ قيمها للمستودع.**

## الفحص

شغّل `python3 scripts/check_core.py` لفحص تماسك الملفات وصياغة JavaScript وXML. هذا الفحص لا يغني عن البناء الفعلي `assembleRelease` ولا اختبار Google والمكالمات على جهازين.
