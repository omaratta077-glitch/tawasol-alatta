# تواصل العطا — إصدار 1.0.27

## ما تم تغييره؟

- استرجاع كود مشغل يوتيوب من **الإصدار 1.0.21 فقط**. المشغل المباشر هو الافتراضي مرة أخرى، دون مشاركة تفضيلات التشغيل المحفوظة التي أضيفت لاحقًا.
- زيادة ارتفاع مشغل يوتيوب في الشاشة العادية إلى **320dp** بدلاً من النسبة 16:9 قصيرة الارتفاع.
- وضع ملء الشاشة يستخدم المساحة المتاحة داخل النافذة، مع بقاء أزرار التكبير والتصغير.
- في طلب **إكمال تسجيل حساب Google فقط**: إذا أعاد خادم Cloudflare القديم رمز **409** مع النص القديم «تعذر إنشاء الحساب. تواصل مع الإدارة.» فإن التطبيق يعرض الرسالة الدقيقة «اسم المستخدم موجود بالفعل، اختر اسمًا آخر.»، لأن هذا النص مرتبط في خادم النسخة القديمة حصرًا بتعارض اسم المستخدم.
- تبقى رسائل الأخطاء الأخرى كما يعيدها الخادم، ولا تظهر رسالة تكرار الاسم بصفة ثابتة.
- بقية تعديلات v1.0.26 بدون تغيير.
- `versionCode = 127` و`versionName = "1.0.27"`.

## رفع GitHub

ارفع محتويات المشروع (وليس ملف ZIP كما هو) إلى جذر المستودع، ثم نفّذ `Build AL-ATTA Official Release APK`.
اسم Artifact المتوقع: `Tawasol-Alatta-Official-v1.0.27` إذا نجح البناء.

## تصحيح رسالة الخطأ داخل Cloudflare أيضًا

تعديل Android يعمل على واجهة التطبيق وحدها، لكنه لا يغير رسالة واجهة الويب أو API على الخادم. لتصحيح أصل المشكلة على الخادم، يوجد ملف مساعد آمن:

`scripts/fix_cloudflare_google_duplicate_v127.py`

شغّله **على أحدث مصدر Worker في مستودع Cloudflare الصحيح** من جذر المستودع بعد أخذ نسخة احتياطية:

`python scripts/fix_cloudflare_google_duplicate_v127.py`

يغيّر فقط فرع `if(await this.user(username))` ذي رسالة الخطأ القديمة إلى رسالة «اسم المستخدم موجود بالفعل» مع رمز `USERNAME_TAKEN`. يفشل بأمان إذا لم يجد النص المتوقع؛ ولا يستبدل ملفات الخادم القديمة أو ينشره تلقائيًا. يجب نشر Cloudflare Worker بشكل منفصل بعد التعديل.

## حدود الاختبار

تمت مقارنة مشغل اليوتيوب مع مصدر 1.0.21 وفحص النسخة/التغييرات داخل ZIP، لكن لم يتم بناء APK أو اختبار التشغيل على هاتف أو نشر التعديل إلى Cloudflare.
