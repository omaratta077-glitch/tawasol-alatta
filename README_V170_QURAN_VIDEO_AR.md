# تواصل العطا — v1.0.70 / Build 170

هذا الإصدار مبني على ملفات المستودع الكامل المصححة v1.0.69، من دون إنشاء فرع جديد أو إضافة مشغّل يوتيوب آخر.

## المصحف الشريف

- شاشة مصحف مستقلة بألوان عاجية وبنية قريبة من صورة المستخدم، بلا زر رجوع داخل المصحف. زر رجوع أندرويد الأصلي يعيد للشاشة السابقة.
- التنقل عبر 604 صفحات، وفهرس 114 سورة، و30 جزءًا، و240 ربع حزب؛ النقر على اسم السورة أو الجزء يفتح موضع بدايته.
- الضغط على نص الآية أو رقمها يفتح خيارات القراءة؛ الضغط المطول يُظهر التفسير الميسر عند توفره.
- تشغيل صوتي من الآية المحددة أو أول السورة، مع المنشاوي (مرتل ومجود)، وعبد الباسط عبد الصمد (مرتل ومجود)، والحصري. تُسحب المقاطع الصوتية من مصدرها ولا تُضمَّن في APK.
- مصدر النص والفهرس والتفسير والصوت: Al Quran Cloud (https://api.alquran.cloud/v1/)، ويتطلب اتصالًا بالإنترنت. عند فشل الخدمة تظهر رسالة واضحة وإعادة المحاولة.
- النص عثماني وحدود الصفحات مبنية على ترقيم المصحف المدني، لكن رسم الحروف وتوزيع الأسطر **ليس صورة مطبوعة مطابقة بكسلًا لبكسل**؛ مطابقة الصفحة المطبوعة تحتاج ملف صور مصحف مرخص/خط متخصص مع مراجعة.
- حفظ آخر صفحة وعلامة مرجعية على الجهاز.

## فيديو المكالمات

- لم نغيّر المحرك أو مسارات WebRTC أو الخادم أو مشغّل يوتيوب.
- عُدلت لوحة Canvas المصغرة لتبقى مخفية حين تُرجع إطارًا أسود بدل أن تغطي معاينة الفيديو الحية. الكاميرا لا تُفتح مرتين؛ نفس MediaStream يظل مستخدمًا للعرض والإرسال.
- عند تعثر الصورة يعرض التشخيص حالة مسار الكاميرا ومقاس إطار الفيديو؛ يجب اختبار ظهور الصورة على HONOR فعلًا قبل الجزم بالإصلاح.

## الاختبارات

نفّذ:

```
python3 scripts/check_core.py
node scripts/test_quran_reader.mjs
node scripts/test_call_video_stage.mjs
```

فحوص المصدر واختبارات JavaScript/خادم المشروع نجحت في البيئة المحلية. لم تُجرَ تجربة على جهاز HONOR، ولم يُبنَ APK محليًا (لا تتوافر أدوات Android SDK هنا).

## الرفع

افتح مجلد مشروعك الأصلي المحتوي على `.git` في GitHub Desktop. فك ضغط الملف الكامل ثم انسخ محتويات مجلد `tawasol-alatta` فوق محتويات مشروعك، وراجع تغييرات الملفات، ثم Commit وPush إلى `main`. لا تستبدل `.git` ولا تستخدم فرعًا جديدًا. يصدر ملف APK باسم `tawasol-alatta-v1.0.70.apk` عند نجاح GitHub Actions، بالتوقيع الرسمي الموجود في إعدادات المستودع.

لتجربة صفحة مطابقة للصورة المُرسلة: افتح قسم «القرآن» ← الفهرس ← «الصفحات» ← 356 (سورة النور / الجزء 18).
