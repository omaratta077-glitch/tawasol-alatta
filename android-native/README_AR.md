# تواصل العطا — تطبيق Native تجريبي

هذا مشروع **Kotlin + Jetpack Compose** مستقل تمامًا عن WebView، بنفس هوية الأسود والذهبي.

## المنفذ حاليًا
- تسجيل الدخول بحساب الموقع من `/api/login`.
- عرض أحدث المنشورات النصية من `/api/posts`.
- نشر منشور نصي إلى نفس السيرفر.
- تسجيل الخروج وتحديث المنشورات.

## غير منفذ بعد
إنشاء حساب، استعادة الجلسة بعد إغلاق التطبيق، الصور والفيديوهات، التعليقات، الإعجابات، الأصدقاء، الرسائل، المكالمات، إشعارات الدفع، الملف الشخصي. هذه نسخة تأسيسية وليست بديلًا كاملًا للتطبيق الحالي.

## GitHub Actions
انسخ مجلد `android-native` إلى جذر المستودع، ثم انسخ ملف `.github/workflows/build-native-apk.yml` المرفق إلى نفس المسار في المستودع. من Actions اختر `Build AL-ATTA Native APK` ثم Run workflow. بعد النجاح نزّل Artifact.

لا يتطلب تعديل Cloudflare أو `android-app` أو `android-studio`.

ملاحظة: لم يُنفذ Gradle build فعليًا في هذه البيئة؛ نجاح البناء يحتاج تحققًا من GitHub Actions.
