# AL-ATTA TV Gold Companion (اختبار آمن)

هذا تطبيق **مرافق مستقل** بحزمة com.alatta.tv وتصميم أسود وذهبي.
لا يعيد توقيع أو تغيير أو توزيع ملفات YTV PRO أو النسخة التي نجح بها البث.
يلزم أن يكون المشغل الشغال com.ytv.pronew مثبتًا كذلك.

- من الأيقونة يفتح واجهة AL-ATTA TV الذهبية وزر فتح المشغل.
- من تواصل العطا (بعد تحديثه)، يستقبل Intent.ACTION_VIEW و id كـ Long و type=1 ويعيد تمريرهما مباشرة للمشغل العامل عبر SplashActivity.
- إن غاب التطبيق المرافق، يظل العطا يفتح المشغل العامل بالطريقة السابقة بلا تغيير.
- لا يسمح هذا الغلاف بفتح قنوات غير مصرح بها أو تجاوز الحماية.

نسخة الاختبار لا تضمن أن واجهة المشغّل الأصلي الداخلية ستتحول إلى الذهبي؛ الواجهة الخارجية فقط هي الذهبية.
