# تجربة مشغل القنوات داخل العطا — 1.0.192

تضيف هذه النسخة تبويب «البث المباشر» مكان «المباريات» داخل شاشة الرياضة. عند اختيار قناة منه بحساب المدير، تُجلب بياناتها الحالية ويستخدم مشغل Media3 الموجود في التطبيق الرابط وترويساته. إذا فشل خيار أو لم يبدأ خلال 20 ثانية، ينتقل إلى الخيار التالي مرة واحدة لكل خيار. لا يفتح التطبيق الخارجي تلقائيًا أثناء التجربة. جدول المواعيد باقٍ تحت «جدول اليوم» داخل التبويب نفسه.

زر «نسخ نتيجة التجربة» ينسخ رقم خطأ المشغل وحالة HTTP إن توفرت ونتائج الخيارات، دون روابط البث أو قيم الترويسات. تبويب «القنوات» يحتفظ بطريقة التشغيل المعتادة. المستخدمون الآخرون يحتفظون بقنواتهم المعتادة؛ تجربة حل أرقام المصدر داخل المشغل متاحة للمدير حتى اختبارها فعليًا.

المسار `/api/admin/football/playback-test` يتطلب جلسة مدير ويختار رقم المصدر من القناة المسجلة حاليًا، فلا يحتاج المستخدم لنسخ أرقام متغيرة. يستخدم قارئ الرد الحالي وSecrets الموجودة. لا تُضمّن مفاتيح القراءة أو المزامنة أو التجربة في APK، ولا تُخزّن روابط التشغيل في قاعدة البيانات. لا يجلب الخادم ملفات الفيديو؛ الهاتف يجلب الوسائط مباشرة.

HTTP مسموح فقط لعائلتي CDN المرصودتين في التقاط المالك (`new-redirect.online` و`cdnarvo.buzz`)؛ بقية التطبيق يحتفظ بمنع HTTP. لا تُغيّر التوقيعات أو الروابط، ولا تُتجاهل ترويسات مطلوبة أو إعدادات DRM غير مدعومة. الروابط التي تحتاج معالجة خاصة قد تستمر في الفشل، ويجب تقييمها من تقرير الاختبار الحقيقي.

البناء الآلي يتحقق من اختبارات المصدر وأندرويد ثم ينشر `tawasol-alatta-v1.0.192.apk` بالتوقيع الرسمي. التحديث المستقل لأرقام القنوات وتعديلات الأذكار في 1.0.191 محفوظة. نجاح البناء لا يثبت نجاح البث؛ الاختبار الفعلي يجريه المالك على هاتفه.
