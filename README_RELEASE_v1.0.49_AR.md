# تواصل العطا — مراجعة المكالمات v1.0.49 (نسخة اختبار قبل النشر)

- إشارة المكالمة الواردة: WebSocket + قائمة HTTP قصيرة لاستقبال المكالمات أثناء فتح تطبيق أندرويد؛ قائمة الإشارات تُملأ من `/api/message-send` في Worker.
- تُرسل حالة «يرن الآن» فقط بعد ظهور نافذة المكالمة لدى الطرف المستقبل، ويبدأ عداد مدة المكالمة فقط بعد اتصال ICE/WebRTC.
- رنين المتصل: نبضتان قصيرتان تتكرران، مختلفتان عن نغمة الاستقبال الأساسية للجهاز.
- فيديو أندرويد: طبقة WebView مع تسريع عتادي، تحقق من بدء إطار فيديو صالح، وزر «إعادة إظهار الفيديو» لمحاولة تشغيل الوسائط بإجراء من المستخدم.
- أذونات أندرويد: طلب الميكروفون والكاميرا موجود أصلًا، وأُضيف مسار فتح إعدادات الأذونات عند الرفض.
- نشاط المستخدم: «نشط الآن» للاتصال الحالي و«نشط منذ ...» من آخر اتصال محفوظ على الخادم.
- لا تغيير لاسم الحزمة `com.alatta.nativeapp` أو مسار التوقيع الرسمي أو مفاتيح Google.

## ترتيب التحديث

1. احفظ نسخة/فرع Git قبل الاستبدال. لا تحذف `.git`.
2. لا تخلط ملفات v1.0.47 أو v1.0.48 القديمة مع هذا المشروع الكامل.
3. ارفع المصدر إلى فرع مراجعة أولًا، وتحقق من نجاح GitHub Actions وبناء APK.
4. في النشر الفعلي، يلزم أن يتوافق تحديث Cloudflare Worker مع تحديث APK، لأن استقبال الدعوات الاحتياطي يعتمد على الخادم الجديد.
5. جرّب: لابتوب ← موبايل، موبايل ← لابتوب، صوت وصورة، دعوة/رنين/رد/عداد/إنهاء/رفض/أذونات.

## الحدود

- **لا يوجد دعم إشعارات FCM أو استقبال مضمون بعد إغلاق التطبيق أو قتله.** المزامنة الاحتياطية تعمل أثناء وجود التطبيق مفتوحًا في الواجهة.
- لا يمكن ضمان فيديو على كل أجهزة أندرويد دون تجربة WebView وWebRTC والصلاحيات الفعلية على الجهاز.
- فحوص المصدر لا تعني نجاح APK أو مكالمة حقيقية؛ يجب مراجعة GitHub Actions وتجربة هاتفية.
