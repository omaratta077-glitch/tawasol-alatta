# تواصل العطا — 1.0.169 (Build 269) — بث الشاشة في صفحة الرياضة

## التغيير

- إضافة بطاقة بث مباشر إلى تبويب الرياضة.
- يقتصر بدء البث وإيقافه على المدير الرئيسي؛ المشاهدة تتطلب تسجيل الدخول.
- يستخدم Android MediaProjection، ويعرض النظام موافقته عند كل جلسة مشاركة شاشة.
- يمرر Worker مفاتيح Cloudflare Realtime بشكل آمن، ويحتفظ بحالة الناشر والمشاهدين، وينهي جلسات SFU عند الإيقاف.
- إضافة إشعار foreground مستمر أثناء مشاركة الشاشة.

## إعداد Cloudflare

أضف في Worker `tawasol-alatta`:

- `CLOUDFLARE_REALTIME_APP_ID` كـ Text.
- `CLOUDFLARE_REALTIME_APP_SECRET` كـ Secret.

لا تضع السر في المستودع أو التطبيق. يرسل Android صورة الشاشة عبر Realtime SFU؛ مسار الصوت الداخلي للفيديو غير مشمول في هذا الإصدار.

## التحقق

اجتاز `scripts/check_core.py` وفحص JavaScript و`git diff --check`. يجب أن يجتاز التغيير بناء Android في CI، ثم يُختبر بدء البث ومشاهدته وإيقافه على جهازين فعليين. لا تتوفر بيئة Android SDK في بيئة التحرير المحلية.
