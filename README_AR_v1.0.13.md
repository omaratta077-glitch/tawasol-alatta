# تواصل العطا — v1.0.13 | تحسين شريط كتابة المحادثة

هذا التعديل لشاشة **المحادثة** فقط، مع الحفاظ على Google والمكالمات والإرفاقات ونظام التحديث داخل التطبيق.

## اللي اتغير

1. شريط كتابة الرسالة **تحت المحادثة**، وعند ظهور لوحة المفاتيح يبقى **فوقها مباشرة** بدل ما يقفز فوق الشاشة.
2. ضبط `android:windowSoftInputMode="adjustResize"` للنشاط الرئيسي.
3. حقل أصغر بحد ذهبي، خلفية سوداء، ونص مكتوب بالأبيض واضح، ومؤشر إدخال ذهبي.
4. زرا «+» و«إرسال» أكبر (52dp) ومسافة متساوية بينهم وبين حقل الكتابة.
5. تحتفظ قائمة «+» بالصور والفيديوهات والملفات الصوتية وPDF.
6. زيادة رقم النسخة إلى **1.0.13 / versionCode 113** حتى يكتشفها نظام التحديث.

## الرفع من GitHub بدون تنزيل الملفات على جهاز الشركة

افتح فرع `main`؛ الملفات الثلاثة المعدلة في الحزمة الصغيرة:

- `android-native/app/src/main/java/com/alatta/nativeapp/MessengerChat.kt`
- `android-native/app/src/main/AndroidManifest.xml`
- `android-native/app/build.gradle.kts`

استبدل الملفات في **نفس المسارات** ولا تضف مجلدًا جديدًا داخل `android-native`، ثم اضغط Commit changes على `main`.

بعدها: Actions → **Build AL-ATTA Official Release APK** → Run workflow (main).
الإجراء الموجود حاليًا بالمشروع ينشر APK موقّعًا في GitHub Releases عند نجاح البناء، ثم تظهر النسخة كـ تحديث داخل التطبيق.

## اختبار مطلوب

- افتح محادثة واكتب نصًا عربيًا طويلًا؛ تأكد أن الأحرف ظاهرة في الحقل.
- افتح لوحة المفاتيح؛ يجب أن يبقى شريط الإدخال عند حافتها العليا **أسفل المحادثة**.
- جرّب زر «+» وإرسال رسالة ثم إغلاق لوحة المفاتيح.

**التحقق المنجز:** مراجعة المصدر والفحوص الثابتة وملف AndroidManifest. **لم يتم بناء APK محليًا أو اختباره على هاتف**؛ نجاح GitHub Actions وتجربة الجهاز مطلوبان للتأكيد.
