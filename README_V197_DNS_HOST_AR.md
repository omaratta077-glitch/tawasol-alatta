# تحديد اسم خادم البث المتعذر — 1.0.197

أظهر تقرير الهاتف في 1.0.196 خطأ DNS أثناء تحميل المصدر الأول، لكن التقرير أخفى اسم الخادم أيضًا. أما لقطة DNS الجديدة التابعة لـYTV PRO فأظهرت استجابة ناجحة للاسم `rex.new-redirect.online` في وقت الالتقاط. لا يثبت ذلك أن العطا يحاول الاسم نفسه أو أن فشله في نفس ظروف الالتقاط. العنوان الذي رجع في الصورة معلومة وقتية، ولم يُثبت داخل التطبيق.

يضيف التقرير `sourceHost` لاسم المصدر المختار، و`requestHost` لاسم طلب التحميل، و`dnsHost` للاسم الذي يذكره UnknownHostException إن جاء بصيغة معروفة. يمكن بذلك تمييز طلب المصدر الأول عن اسم لاحق قد يفشل بعد تحويل. استخراج اسم DNS لا يعرض نص الاستثناء؛ يحتفظ فقط باسم DNS عام صالح، ويرفض الروابط والمسارات والاستعلامات وبيانات المستخدم وعناوين IP وأسماء الشبكات المحلية. تبقى قيم الترويسات وروابط البث الكاملة خارج التقرير.

هذا تحديث تشخيصي؛ لا يغيّر مسار طلب بيانات التشغيل أو إعداد DNS أو التحقق من الشهادات أو ترتيب المصادر أو المهل أو الصلاحيات. يحتفظ بالمشغّل نفسه وجلسة التشغيل وتقرير الإغلاق. لا يتصل المساعد أو CI بمصدر القنوات أو خوادم البث. تستخدم الاختبارات أسماء وهمية ونقلًا تجريبيًا فقط.

تغطي الاختبارات تمييز اسم الطلب عن اسم فشل DNS، وعدم تسريب نصوص الخطأ وروابطها، ورفض مدخلات الأسماء غير الصالحة والمحلية، مع استمرار اختبارات نافذة الفيديو والتبديل والنسخ.

الإصدار 1.0.197، رقم البناء 297، وملف التحديث `tawasol-alatta-v1.0.197.apk` بالتوقيع الرسمي. المطلوب من تجربة المالك تقرير جديد يظهر أسماء الخوادم والنتيجة بعد تجربة المصدرين.
