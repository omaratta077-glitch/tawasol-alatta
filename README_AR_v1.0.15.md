# تواصل العطا v1.0.15 — تحديث نافذة التحديث بالأسود والذهبي

## ماذا تغير؟
- استبدال نافذة التحديث الافتراضية فاتحة اللون بتصميم أصلي أسود وفحمي بإطار ذهبي.
- استخدام شعار A الحقيقي من موارد التطبيق الحالية، عنوان أبيض، معلومات الإصدار بالذهبي، وشريط تقدم ذهبي.
- تنسيق حالات: تحديث متاح، التنزيل ونسبته، جاهز للتثبيت، السماح بالتثبيت، وخطأ التنزيل.
- الإبقاء على مسار تنزيل ملف APK الرسمي داخل التطبيق، وإشعار أندرويد بتثبيته بموافقة المستخدم.
- الإصدار الداخلي: versionCode = 115 و versionName = 1.0.15 حتى يظهر كتحديث فوق v1.0.14.
- تصحيح قوس Kotlin المعروف في تسجيل حساب Google الموجود في نسخة المصدر المرجعية، بدون تغيير منطق التسجيل.

## تثبيت التعديل
1. افتح مستودع github.com/omaratta077-glitch/tawasol-alatta وحدد الفرع main.
2. ارفع محتويات `android-native` المرفقة إلى نفس المسارات في المستودع، مع استبدال الملفات الحالية (لا تُنشئ android-native داخل android-native).
3. Commit changes ثم Actions > Build AL-ATTA Official Release APK > Run workflow.
4. إن نجح البناء ونُشر v1.0.15 في Releases، سيظهر من داخل التطبيق إذا كان المثبت عندك إصدارًا أقدم.

## إن كنت تريد أقل تعديل ممكن
استخدم أرشيف Hotfix في نفس التسليم؛ يحتوي على ملفين فقط: AppUpdateChecker.kt وbuild.gradle.kts. لا يستبدل باقي ملفات التطبيق. يُنصح برفع ملفات الحزمة المصغرة إذا كانت بقية الملفات الموجودة على GitHub أحدث من المصدر المرجعي.

## حدود التحقق
تم فحص ملفات المشروع والتعديل بنيويًا، لكن لم يُبنَ APK في هذه البيئة؛ البناء النهائي يُختبر في GitHub Actions على حسابك.
