# تواصل العطا — إصلاح أزرار الملف الشخصي v1.0.15

هذا الإصلاح يصحح تقطيع كلمات الأزرار في صفحة الملف الشخصي العامة.

- زر «محادثة»، «صوتي»، «مرئي»: الأيقونات أعلى النص داخل أزرار متساوية العرض والارتفاع، ونص سطر واحد.
- تبويبات «المنشورات»، «الصور»، «الفيديوهات»: أحجام متساوية، نص لا ينقسم لسطرين.
- لم يتم تغيير منطق الضغط على الأزرار أو الاتصال أو تسجيل Google.
- رفع الإصدار إلى versionCode 115 / versionName 1.0.15 لاستقبال التحديث داخل التطبيق.

## الرفع على GitHub

1. افتح المستودع على الفرع main.
2. استبدل الملفين في مساريهما الأصليين:
   - android-native/app/src/main/java/com/alatta/nativeapp/UserProfileScreen.kt
   - android-native/app/build.gradle.kts
3. Commit changes.
4. شغّل .github/workflows/build-native-release.yml على فرع main.

**تنبيه**: إصلاح مبني على الملفات المتاحة من حزمة v1.0.14. إذا كانت تغييرات أخرى قد أضيفت لهذه الملفات على GitHub، راجع الفرق قبل الاستبدال لكي لا تمحوها. تم فحص الملفات والتغييرات نصيًا، ولم يتم تنفيذ بناء Android أو اختبار على هاتف.
