# AL-ATTA MEDIA — approved primary logo

The approved mark is `alatta-media-master.png`: the gold A, people and book on black, with AL-ATTA above a smaller centered MEDIA. Preserve this artwork and the project’s existing black/gold UI theme.

Derived assets are the shared 512px website/native/store logo, Android launcher density images, padded adaptive foregrounds, and PWA/Apple touch icons. Android notification large icons use `drawable/logo_premium`; status icons use the existing monochrome A (`atta_notification_icon`) required by Android.

The original generated master is kept here unchanged. Asset resizing is build preparation only; no artwork or lettering is redrawn.
