# تواصل العطا — تحسين واجهة إنشاء الحساب v1.0.24

## ما تغير
- زر **إنشاء حساب عن طريق جوجل**: يظهر النص كاملًا بخط أبيض، وأيقونة Google على اليمين، مع السماح بسطرين عند تكبير خط الهاتف بدل قص النص.
- زر إكمال التسجيل **بعد اختيار حساب جوجل**: النص الآن **تأكيد إنشاء الحساب** فقط. طريقة التحقق من Google لم تتغير: لا يوجد كود بريد إضافي بعد نجاح توثيق جوجل.
- خانة **تاريخ الميلاد**: قبل الاختيار تظهر هذه العبارة وحدها في منتصف الخانة، بدون «اليوم / الشهر / السنة». الضغط ما زال يفتح منتقي التاريخ ويحفظ تاريخًا صحيحًا.
- **كل مدخلات التسجيل بالبريد محفوظة**: الاسم الكامل، اسم المستخدم الفريد، تاريخ الميلاد، الهاتف، البريد، النوع، الدولة، المدينة، كلمة المرور وتأكيدها. التسجيل بالبريد ما زال يرسل كود التأكيد، ولا يتم تجاوزه.
- **إكمال التسجيل بجوجل محفوظ**: البريد الموثق، الاسم الكامل، اسم المستخدم، تاريخ الميلاد، المدينة؛ لا تُطلب كلمة مرور أو كود بريد عند التسجيل بجوجل. يبقى تاريخ الميلاد مطلوبًا واسم المستخدم لا بد أن يكون فريدًا.
- جميع شاشات التطبيق الأخرى، بما فيها يوتيوب، كما هي في v1.0.23.

## التركيب
- **مشروع كامل**: افتح مجلد `android-native` في Android Studio (أو استخدم إجراء GitHub Actions للبناء بعد تحديث المستودع).
- **تصحيح صغير**: انسخ الملفات من ZIP التصحيح إلى *نفس المسارات* في مستودع المشروع، ولا تحذف بقية الملفات. ملفات التصحيح: `MainActivity.kt`، `PremiumAuth.kt`، `AttaBirthDatePicker.kt`، `app/build.gradle.kts`.
- بعد رفع الملفات شغّل GitHub Actions: `Build AL-ATTA Official Release APK`، باستخدام **مفتاح التوقيع الأصلي**، وليس مفتاحًا جديدًا.
- ما زال تفعيل التسجيل بجوجل معتمدًا على إعدادات Google OAuth وCloudflare التي كانت مطلوبة في v1.0.23. تغيير الواجهة وحده لا يفعّل إعداد خادم ناقصًا.

## التحقق
فحص نصوص Kotlin والتأكد من بقاء كل الحقول ومسار OTP منفصلًا عن Google، وسلامة ZIP. لم يتم تجميع APK أو تشغيل اختبار على هاتف في هذه البيئة.
