# تواصل العطا — v1.0.22

## 1) إنشاء حساب Google — الإصلاح الأهم
- اختيار «إنشاء حساب عن طريق Google» يستدعي منتقي Google الأصلي، ثم يفتح نموذج الحساب الجديد مباشرة: الاسم الظاهر، **اسم مستخدم يختاره الشخص**، تاريخ الميلاد من التقويم، والمدينة (اختياري).
- الضغط على «إنشاء الحساب باستخدام Google» يرسل ID Token إلى Cloudflare للتأكد من توقيع Google، وتأكيد البريد، واسم المستخدم وتاريخ الميلاد، ثم يسجل الدخول مباشرة **بدون إرسال كود بريد آخر**.
- أما التسجيل بالبريد وكلمة المرور فلا يزال يستخدم كود تحقق مستقل. الحسابات القديمة لا تُحذف أو تُعدَّل.
- في النسخ القديمة ظهر خطأ «لا يوجد حساب Google سابق» لأن زر الإنشاء طلب من الخادم الدخول قبل استكمال بيانات إنشاء الحساب. أصبح مسار الإنشاء منفصلًا عن الدخول.
- إذا كان الخادم غير محدَّث يظهر **سبب واضح عند الضغط على الزر** بدل تعطّله بصمت. يجب نشر Cloudflare أيضًا لأن حفظ الحساب يتم في الخادم.

## 2) يوتيوب — إعادة تشغيل الفيديو وتحسين أدوات التحكم
- التشغيل المباشر الذي نجح في 1.0.19 هو الوضع الافتراضي، مع الاحتفاظ بـIFrame كخيار تجريبي بديل.
- أزرار **ملء الشاشة/الرجوع، تكبير/تصغير** منفصلة وواضحة ولا تزاحم أزرار التقديم؛ وضع ملء الشاشة يستغل المساحة الرأسية المتاحة بدل مربع صغير ثابت.
- عند تشغيل YouTube المباشر يحاول التطبيق قراءة حالة الفيديو والتحكم في موضعه (±10 ثوانٍ والسحب) عندما يسمح WebView بذلك. وإذا لم يُتح عنصر الفيديو لهذه الأوامر، تبقى أدوات YouTube الأصلية داخل الفيديو هي البديل الموثوق. بعض الفيديوهات تمنع التضمين نهائيًا.

## خطوات النشر (ترتيب مهم)
1. ارفع محتويات حزمة `AL_ATTA_Google_YouTube_v1.0.22_Patch.zip` إلى **جذر مستودع GitHub** على الفرع `main`، محافظًا على أسماء المجلدات (`android-native`، `scripts`، `.github`) واضغط **Commit changes**.
2. افتح GitHub Actions وشغّل **Apply AL-ATTA Google Signup v1.0.22**؛ هذه المهمة تفحص الكود الحالي وتضيف علامة `googleSignupVersion:122` لخادم Cloudflare **فقط إذا كان مسار إنشاء Google السليم موجودًا**. في حال SAFE ABORT لا تُجبر التعديل ولا تستبدل worker.js بملف قديم؛ استكمل تحديث المصادقة السابق أولًا.
3. **انشر ملف Cloudflare Worker المحدث على Cloudflare** بالطريقة المستخدمة في مشروعك. نجاح Action بمفرده لا يعني أن الموقع الحي اتحدث.
4. للتحقق بعد النشر افتح `https://tawasol-alatta.omaratta077-4fd.workers.dev/api/google-config` وتأكد أنه يحتوي على `"googleSignupVersion":122` و`"nativeUsernameSignup":true` و`"birthDateSignup":true`. قيمة `clientId` عامة وليست كلمة مرور. إذا لم تظهر النسخة الجديدة فالخادم لم يُنشر بعد.
5. بعد التأكد من النشر، شغّل **Build AL-ATTA Official Release APK** من `main`. حدّث التطبيق إلى `1.0.22` بعد نجاح البناء ونشر APK الموقّع في GitHub Releases.
6. اختبر إنشاء حساب Google جديد لا يرتبط بحساب سابق: اختيار Google، إدخال الاسم واسم المستخدم والتاريخ، «إنشاء الحساب»؛ يجب الانتقال مباشرة إلى الرئيسية من دون إرسال كود تأكيد بريد. ثم اختبر الفيديو وتقديمه وملء الشاشة.

## تنبيهات
- الملف `cloudflare-site/src/worker.js` **غير مطلوب رفعه يدويًا** ضمن حزمة التعديل الصغيرة؛ المهمة تحدث الملف الحالي بأمان. لا ترفع نسخة قديمة من الخادم فوق GitHub.
- التسجيل بالبريد وكلمة المرور ما زال يحتاج كود التأكيد، وهذا منفصل عن Google.
- لا تغيّر SHA-1 أو Client ID أو أسرار GitHub أو مفتاح توقيع APK.
- تمت مراجعة الكود وفحص صياغة JavaScript وملفات الحزمة، لكن **لم يُبْنَ APK هنا، ولم تُجرّب Google أو YouTube على هاتف فعلي**؛ لا يُضمن نجاح التشغيل قبل اختبار النسخة.
