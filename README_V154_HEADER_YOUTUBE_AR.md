# تواصل العطا 1.0.54 (Build 154)

- الهيدر بشعار التطبيق وأيقونات الرسائل والإشعارات يظهر في الرئيسية فقط.
- باقي الصفحات لها صف عنوان واحد صغير بدون زر تحديث. الرئيسية لا تعرض صف بحث زائد تحت الهيدر.
- حُذف زر يوتيوب من الهيدر في الصفحات الفرعية، مع بقائه في الشريط السفلي.
- صفحة يوتيوب تعرض حقل بحث أفقيًا بزر بحث واحد، بدون عنوان مكرر ولا حاوية ارتفاعها أكبر من الفيديو.
- Android WebView يُنشئ iframe باستخدام **نفس الملف الأصلي** `cloudflare-site/public/youtube-player-shared.js` المنسوخ تلقائيًا أثناء البناء. لا يعتمد على صفحة Cloudflare المنفصلة التي ربما لم تُنشر؛ حُذفت هذه الصفحة لأنها لم تعد مستخدمة.
- بقيت مشغّلات مكالمات WebRTC وGoogle والموقع بلا تغيير.

**التشغيل الحقيقي يحتاج تجربة APK على الهاتف.** بعض فيديوهات YouTube تمنع التضمين أو تعرض خطأ 153 حسب البيئة، حتى مع المشغّل الرسمي.
