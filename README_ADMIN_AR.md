# إصلاح تشخيص لوحة الإدارة — ملف واحد فقط

استبدل: android-native/app/src/main/java/com/alatta/nativeapp/MainActivity.kt

هذا الملف مبني على نسخة MainActivity المرفوعة سابقًا والمحتوية على تعديلات YouTube.

## مهم: تمكين المدير لا يتم من الواجهة
في Cloudflare Worker → Settings → Variables and Secrets اضبط SUPER_ADMIN_USERNAME على اسم المستخدم (username) الحقيقي لحساب المدير، وليس اسم العرض، ثم أعد النشر إذا لزم. بعد ذلك سجل الدخول مجددًا وافتح القائمة.

النظام يجب أن يرفض الحسابات العادية. التعديل يعرض حالة الدور والأخطاء بدل لوحة فارغة، ويعيد تحميل المستخدمين والمنشورات من الخادم بعد التحقق من الصلاحية.

لم يتم اختبار APK على هاتف؛ اختبر البناء والأذونات قبل الاعتماد. لا تضع أي رمز جلسة في لقطات الشاشة.
