تواصل العطا — تطبيق Android Studio

1. افتح مجلد android-studio في Android Studio.
2. انتظر Gradle Sync (يتطلب الإنترنت).
3. اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
4. ثبّت APK على هاتفك.

التطبيق يفتح الموقع نفسه، لذلك الحسابات والرسائل تظل على Cloudflare.
صلاحيات الكاميرا والمايك تُطلب عند الحاجة فقط.
تنبيه: إشعارات Web Push في الخلفية لا تعمل تلقائيًا داخل Android WebView؛ لإشعارات حقيقية عند إغلاق التطبيق يلزم دمج Firebase Cloud Messaging وخدمة إرسال من السيرفر.
هذه ملفات مصدر وليست APK جاهزًا.
