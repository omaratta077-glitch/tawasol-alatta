# تواصل العطا — تحديث التفاعلات والقائمة v1.0.17

هذا التعديل مبني على ملفات Android للنسخة v1.0.16، ولا يغيّر خادم Cloudflare أو تسجيل Google أو شاشة المكالمات.

## التعديلات

- القلب: نقرة واحدة تبدّل الإعجاب، ويصبح القلب ذهبيًا **ممتلئًا** فورًا عند الإعجاب. تراجع الحالة عند رفض الطلب من الخادم.
- الضغط المطوّل على القلب يفتح قائمة تفاعلات داخل قائمة منبثقة: حب وضحك ودهشة وحزن وغضب. لم تعد تظهر الإيموجي دائمًا أسفل المنشور.
- ترتيب شريط التنقل السفلي (من اليمين إلى اليسار): الرئيسية ← ملفي ← الرسائل ← الأصدقاء ← القائمة. الرسائل في المنتصف.
- إزالة «استكشف» من الشريط السفلي لأن البحث موجود في الأعلى.
- أيقونة القائمة ثلاث خطوط أفقية فعلية.
- داخل القائمة: الملف الشخصي، المحفوظات، المجموعات، الإشعارات، تغيير كلمة السر، وتسجيل الخروج بتأكيد.
- إزالة زر «خروج» القديم من الشريط العلوي لصفحات التطبيق.
- الإصدار: versionCode=117، versionName=1.0.17، ويظل التوقيع الرسمي والإصدارات على GitHub Releases كما كانت.

## التركيب

1. افتح المستودع `https://github.com/omaratta077-glitch/tawasol-alatta` واختر فرع `main`.
2. فك ضغط حزمة الإصلاح الصغيرة وارفع مجلد `android-native` مع الاحتفاظ بمسارات الملفات، واستبدل القديمة.
3. احفظ بـ Commit changes، ثم شغّل `Build AL-ATTA Official Release APK` من GitHub Actions.
4. بعد نجاح البناء ونشر الإصدار، حدّث التطبيق من داخله.

## الاختبار على الهاتف

1. في الرئيسية اضغط القلب: يجب أن يصبح ذهبيًا. اضغطه مجددًا: يجب أن يعود للحالة العادية.
2. اضغط مطولًا على القلب: يجب أن تظهر التفاعلات فقط عند الطلب.
3. تحقق أن الرسائل هي العنصر الأوسط في الشريط السفلي، والقائمة أقصى اليسار.
4. افتح القائمة ثم «تسجيل الخروج»: تأكد أن السؤال التأكيدي يظهر، وأن زر «إلغاء» لا يسجل خروجًا.

## ملاحظة فنية

تم فحص بنية XML ومسارات الملفات واتساق الإصدارات برمجيًا، **ولم يُنفذ بناء APK كامل أو اختبار على هاتف من بيئة إعداد الحزمة**. يلزم نجاح GitHub Actions والاختبار الفعلي.
