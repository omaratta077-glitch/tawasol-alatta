# تواصل العطا 1.0.51 (Build 151) — نسخة كاملة مراجعة

الأساس: النسخة الرسمية v1.0.49 بعد إصلاح Kotlin، ثم تعديلات v1.0.50 الموجودة على مشروع المصدر.

- الاحتفاظ بمعرّف Android `com.alatta.nativeapp` والتوقيع الرسمي وآلية إصدار APK الأصلية.
- `MainActivity.kt`: إصلاح ظهور نوع `internal PushCall` في خاصية عامة: `internal var incomingPush`؛ لا تعديل لتعريف `PushCall`.
- واجهة المكالمات الداكنة وتعديلات فيديو WebRTC وإشعارات Firebase للمكالمات بالخلفية كما جاءت في 1.0.50. هذه الوظائف تحتاج اختبار هاتف + تهيئة Firebase/Cloudflare.
- `YouTubePlayer` واحد، مع وضع تشغيل API ووضع تضمين بديل داخل نفس المكوّن؛ عدم حذف البديل لتجنب تعطّل التشغيل.
- تسجيل Google الأصلي كما هو، دون إعادة واجهة WebBridge القديمة.
- فحص جديد لاكتشاف علامات تعارض Git، وفحص توافق صلاحيات `PushCall`.
- تحديث `versionName=1.0.51` و`versionCode=151` وفحصهما.

## طريقة الاستخدام
فك الضغط وانسخ **محتويات** `tawasol-alatta-main` إلى جذر مستودع GitHub Desktop الأصلي، مع عدم نسخ مجلد `.git` أو استبداله. تجنب الدمج أثناء وجود تعارض مفتوح؛ أنهيه أو ألغِه أولًا ثم انسخ الملفات. بعدها راجع Changes ثم Commit وPush.

## حدود الاختبار
اختبارات Python وNode وفحص تركيب XML/JavaScript لا تبني APK ولا تختبر Google أو الفيديو أو Firebase على جهاز فعلي. يلزم بناء GitHub Actions واختبار هاتف. Firebase يحتاج ضبط Variables في GitHub وسر الخدمة في Cloudflare.
