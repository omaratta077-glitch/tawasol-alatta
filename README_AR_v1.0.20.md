# تواصل العطا — YouTube Controls v1.0.20

## الهدف
إضافة أدوات تحكم للفيديوهات داخل التطبيق بدل الاكتفاء بمشغّل غير قابل للتقديم أو التكبير.

## التغييرات
- مشغّل YouTube IFrame التفاعلي هو الوضع الافتراضي: مناسب للتقديم والتأخير والتوقف المؤقت عبر API الرسمي.
- أزرار رجوع/تقديم 10 ثوانٍ، شريط لسحب موضع الفيديو وعرض الوقت.
- تكبير وتصغير العرض بين 1× و2.5×، وزر ملء الشاشة مع إغلاق والعودة إلى المقطع نفسه.
- إبقاء «التشغيل المباشر (بديل)» من v1.0.19 لو رفض بعض المحتوى وضع IFrame؛ أزرار السحب والتقديم الجديدة لا تتوفر في وضع التشغيل المباشر، لكن تبقى أدوات الفيديو الأصلية إن عرضها YouTube.
- الحفاظ على رابط الرجوع إلى YouTube، فحص جاهزية المشغّل، والتنبيه بعد 15 ثانية بدل التحميل بلا نهاية.
- الإصدار: versionCode=120 وversionName=1.0.20.

## رفع التعديل الصغير
1. افتح مستودع tawasol-alatta واختر الفرع `main`.
2. فك ضغط ZIP وحدث الملفين في نفس مساراتهما الأصلية:
   `android-native/app/src/main/java/com/alatta/nativeapp/MainActivity.kt`
   و`android-native/app/build.gradle.kts`.
3. اعمل Commit ثم شغّل `Build AL-ATTA Official Release APK` على `main`.
4. بعد نجاح النشر في Releases، اختبر التحديث في الهاتف.

## اختبار مقترح
- فيديو عادي: اضغط ▶، ثم ↶ 10 ثوانٍ و10ث ↷، اسحب شريط التقدم، واختبر − / + و⛶ وإغلاق ملء الشاشة.
- عند فشل IFrame، اضغط «التشغيل المباشر (بديل)» أو «فتح في YouTube».
- بعض الفيديوهات أو البث المباشر قد تمنع seek حسب سياسة YouTube ولا يمكن تجاوز ذلك بالقوة.

## حدود الفحص
تم فحص JS باستخدام `node --check`، ومسارات الملفات، وتوافق الإصدار، وسلامة ZIP.
لم يتوفر Android SDK لإجراء Gradle assembleRelease ولم تُختبر وظائف الفيديو على هاتف، لذلك يلزم نجاح GitHub Actions وتجربة حقيقية.
