# تواصل العطا — إصلاح تعليق YouTube v1.0.19

## لماذا كان يظل يحمل؟
مشغّل v1.0.18 لم يكن يتابع استجابة YouTube الفعلية، وقد لا يصل إشعار انتهاء التحميل من WebView عند تعليق الإطار. لا يمكن افتراض أن المشكلة دائمًا في فيديو بعينه.

## ما الجديد؟
- تشغيل مباشر لرابط YouTube الرسمي داخل WebView مع ترويسة Referer التي توصي بها YouTube.
- وضع بديل باستخدام YouTube IFrame Player API؛ يستقبل إشعارات READY/PLAYING وأكواد الأخطاء مثل 100 و101 و150 و153.
- مهلة 15 ثانية تمنع ظهور دائرة التحميل بلا نهاية، وتعرض رسالة مفهومة عند التعليق.
- أزرار تبديل طريقة التشغيل وإعادة المحاولة، وخيار فتح الفيديو في تطبيق YouTube عند تعذر التضمين أو منعه.
- الحفاظ على بقية شاشات التطبيق وتسجيل Google والمكالمات والتوقيع كما هي. رفع versionCode إلى 119.

## طريقة رفع حزمة الإصلاح الصغيرة
1. افتح GitHub واختر الفرع **main**.
2. ارفع `android-native/app/src/main/java/com/alatta/nativeapp/MainActivity.kt` إلى مساره نفسه، ثم `android-native/app/build.gradle.kts`، مع استبدال النسخ السابقة.
3. اضغط Commit changes.
4. شغّل GitHub Actions: `Build AL-ATTA Official Release APK` ثم حدّث التطبيق للإصدار 1.0.19.
5. جرّب فيديو عامًا معروفًا بأنه يسمح بالتضمين. إذا لم يبدأ، اضغط «تجربة مشغّل IFrame». إذا ظهر خطأ 101/150، فالتضمين ممنوع ولا يمكن تجاوزه؛ استخدم YouTube.

## حدود الاختبار
تم فحص النصوص وشفرة JavaScript داخل HTML وترابط الملفات ورقم الإصدار. لم يُجرَ بناء APK فعلي أو تشغيل فيديو على جهاز أندرويد في هذه البيئة؛ نجاح التشغيل يحتاج اختبار GitHub Actions والهاتف.
