# تواصل العطا v1.0.29 — تحميل رسمي وتحديثات اختيارية

هذه النسخة مبنية على المشروع الكامل 1.0.28. لم نغير صفحات الحساب أو المكالمات أو يوتيوب.

## نظام التحديث
- النافذة تظهر فقط عندما يكون إصدار رسمي أحدث منشورًا في GitHub Releases، والمستخدم يختار «تحديث الآن» أو «لاحقًا» بدون حظر استخدام التطبيق.
- يتحقق تطبيق Android من `https://api.github.com/repos/omaratta077-glitch/tawasol-alatta/releases/latest` عند فتحه، ويبحث عن ملف `tawasol-alatta-vX.Y.Z.apk` ضمن ملفات الإصدار الجديد.
- Android نفسه يتولى طلب موافقة المستخدم على التثبيت. لا يوجد تثبيت صامت.

## التوزيع التلقائي
- ملف `.github/workflows/build-native-release.yml` يعمل عند رفع تغييرات Android إلى فرع `main`، ويظل التشغيل اليدوي متاحًا.
- بعد نجاح البناء وفحص التوقيع تُنشر نسخة APK على GitHub Releases باسم إصدارها، وباسم ثابت `tawasol-alatta-latest.apk`.
- رابط التنزيل الثابت للموقع: `https://github.com/omaratta077-glitch/tawasol-alatta/releases/latest/download/tawasol-alatta-latest.apk`.
- أضفنا `cloudflare-site/download/index.html` كصفحة تحميل مستقلة. يجب أن يكون إعداد نشر موقع Cloudflare يشمل هذا المسار حتى تعمل صفحة `/download/`. الزر الموجود بالصفحة الرئيسية يحتاج الربط بهذا المسار بشكل منفصل.

## مهم قبل التوزيع
1. تأكد أن GitHub Actions لديها Secrets التوقيع المطلوبة وأن البناء ناجح. ظهور Artifact وحده لا ينشر Release.
2. كل إصدار Android جديد يحتاج `versionCode` أكبر و`versionName` جديد؛ وإلا فلن ينشر workflow إصدارًا جديدًا مكان إصدار قديم بنفس الوسم.
3. استخدم **مفتاح التوقيع نفسه** و`applicationId` نفسه في كل الإصدارات حتى يتمكن المستخدمون من تثبيت التحديث فوق النسخة الموجودة.
4. لا ترفع مفتاح التوقيع ولا كلمات المرور إلى المستودع.
5. التنزيل من الموقع ليس تثبيتًا تلقائيًا: بعض الهواتف تتطلب السماح بالتثبيت من هذا المصدر؛ والتحذيرات تختلف من جهاز لآخر.
6. لم يتم اختبار بناء APK أو النشر على GitHub / Cloudflare من هذه البيئة، ويجب التأكد عمليًا قبل مشاركة الرابط.
