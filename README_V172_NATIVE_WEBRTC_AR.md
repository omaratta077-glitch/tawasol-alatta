# تواصل العطا — v1.0.72 / Build 172 — إعادة بناء مكالمات أندرويد Native

## المطلوب
- إزالة محرك مكالمات Android HTML/WebView القديم تمامًا وعدم استبداله بفتح صفحة الموقع.
- إنشاء محرك WebRTC أصلي بكوتلن يستخدم كاميرا الجهاز، ميكروفونه، و`SurfaceViewRenderer` للصورتين.
- الصورة المصغرة أعلى اليمين تعرض كاميرا المستخدم قبل رد الطرف الآخر، باستخدام **نفس VideoTrack** المرسل للطرف الآخر.
- الفيديو الكبير يعرض `VideoTrack` القادم من الطرف المقابل، بلا iframe/Canvas أو طبقة WebView سوداء.
- الاحتفاظ ببروتوكول إشارات الموقع عبر Cloudflare والـTURN دون نسخ موقع التصفح أو تغيير تشغيل YouTube والقرآن.

## التغييرات الحقيقية
- ملف جديد `android-native/app/src/main/java/com/alatta/nativeapp/NativeRtcCall.kt`:
  `PeerConnectionFactory`، التقاط Camera2 مع رجوع Camera1، صوت WebRTC، STUN/TURN، SDP Offer/Answer، ICE، حفظ الإشارات في `/api/message-send`، واستقبالها من `/api/conversation`.
- استبدال `NativeCallScreen.kt` بواجهة مكالمة Compose فيها سطحا WebRTC Native بدل WebView، مع إبقاء أزرار التحكم والتصغير، واسم الطرف الآخر ورنة الاستقبال.
- حذف `android-native/app/src/main/assets/atta-call.html` نهائيًا حتى لا توجد نسختان متنافستان لمحرك المكالمات.
- إضافة مكتبة WebRTC من Maven Central `io.github.webrtc-sdk:android:137.7151.03`، وتحديث رقم الإصدار إلى 172، وتحديث اختبارات GitHub Actions وفق البنية الجديدة.

## مهم قبل اعتبار الإصلاح ناجحًا
اختبارات المصدر وNode/Python لا تضمن نجاح بناء Kotlin أو عرض الكاميرا؛ Android SDK وGradle وتنزيل مكتبة WebRTC غير متاحين لبيئة التحضير الحالية، **لذلك هذا المشروع لم يُبنَ كـAPK بعد**.

1. ارفع ملفات المشروع إلى `main` داخل مشروع Git الأصلي ولا تحذف مجلد `.git`.
2. انتظر Build AL-ATTA Official Release APK حتى ينتهي بناء Kotlin والتوقيع؛ لا تُثبّت قبل نجاح هذا البناء.
3. اختبر مكالمة فيديو من HONOR إلى المتصفح. ينبغي أن تظهر صورة كاميرتك في مربع أعلى اليمين قبل الرد، ثم الصورة الكبيرة بعد اتصال الطرفين.
4. اختبر الاتجاه العكسي، ثم الصوت والرنين وإغلاق المكالمة. **رنين الخلفية لم يعدّل في هذا الإصدار**.
5. إذا فشل البناء، أرسل أسطر `compileReleaseKotlin` بالكامل حتى نستطيع إصلاح خطأ الترجمة الفعلي من دون لمس يوتيوب أو القرآن.

## ما لم يتغير
- `cloudflare-site/src/worker.js` وبروتوكول الموقع وأصول مشغّل YouTube كما هي.
- واجهة المصحف `atta-quran.html` وتنسيق v1.0.71 كما هما.
- Firebase وإشعارات الخلفية وتسجيل دخول Google كما كانت.
